# 章节复习与模型选择

本页把本教程第 1—16 章涉及的主要模型放在同一条选择路径上。解题时先描述系统规则，再找满足这些规则的模型；不要先看到题目给了 $\lambda$ 和 $\mu$ 就直接套 M/M/1。

![从到达、服务特征和系统规则选择模型](model-selection.webp)

## 模型速查

| 系统特点 | 教材模型 | 先检查什么 |
| --- | --- | --- |
| 单服务台、泊松到达、指数服务、无限队列 | M/M/1 | $\lambda<\mu$ |
| 单服务台、容量有限、满员后拒绝 | M/M/1/K | 状态为 $0,\ldots,K$；用有效到达率计算已接纳顾客的平均时间 |
| $s$ 个并行服务台、共用队列 | M/M/s | $\lambda<s\mu$ |
| 单服务台、泊松到达、一般服务时间 | M/G/1 | 需要 $E[S]$ 与 $E[S^2]$，且 $\lambda E[S]<1$ |
| 有限机器或顾客来源 | 机器维修模型 | 到达率随系统状态变化 |
| 所有服务台忙时直接离开 | M/G/s/s 损失模型 | 提供负荷 $a=\lambda E[S]$ 与阻塞概率 |
| 多个服务站有路由关系 | 开放或封闭网络 | 先解流量关系，区分任务总数是否固定 |
| 到达和服务时间都一般 | G/G/m 近似 | 估计 $C_a^2,C_s^2$，并检验近似是否足够可靠 |
| 顾客等待成本不同 | 优先级模型 | 明确优先顺序、是否允许中断和优化目标 |
| 到达率随时段变化或尚未达稳态 | 瞬态模型 | 给出初始状态与 $\lambda(t),\mu(t)$ |

## 公式关系图

1. **先求负荷**：M/M/1 用 $\rho=\lambda/\mu$；多服务台用 $\rho=\lambda/(s\mu)$；一般服务时间用 $\rho=\lambda E[S]$。
2. **先确认稳态**：无限容量模型通常要求负荷小于 1；有限容量模型有有限状态，但会出现拒绝或损失。
3. **从状态概率到平均人数**：$L=\sum_j j\pi_j$。等待人数要排除正在服务的顾客。
4. **用 Little 定律换算时间**：$L=\lambda_{\mathrm{eff}}W$，$L_q=\lambda_{\mathrm{eff}}W_q$。到达会被阻塞或拒绝时使用有效到达率。
5. **区分排队时间和系统逗留时间**：$W=W_q+E[S]$；$L=L_q+L_s$。

## 常见误区

- 把到达率 $\lambda$ 当作平均到达间隔；两者互为倒数。
- 把多服务台利用率写成 $\lambda/\mu$，忘记总服务能力是 $s\mu$。
- 认为 $\lambda<\mu$ 就代表等待很短；当利用率接近 1 时，等待可能迅速增加。
- 有顾客被拒绝时，仍用外部到达率代入 Little 定律。
- 只比较平均服务时间，忽略服务时间的方差和分布形状。
- 看到“指数假设没有被检验拒绝”就认为它一定正确；检验只能发现明显冲突。
- 对时变到达率直接套用稳态公式；高峰时段和初始条件可能决定瞬时表现。

## 自测

1. 到达率为每小时 12 人、服务率每小时 15 人的单服务台 M/M/1，稳态是否存在？若存在，$\rho$ 是多少？
2. 一家门诊有 4 个医生，所有患者进入同一等待区。与每位医生各有一条队伍相比，服务规则差异会怎样改变模型？
3. 呼叫中心最多容纳 25 位顾客（包括正在通话者）。满员时来电者会被拒绝。应看哪个状态概率估计拒绝比例？
4. 一项工作流固定包含 8 个循环任务，任务在 CPU 与磁盘之间流转。它属于开放还是封闭网络？
5. 如果实际服务时间的平方变异系数远大于 1，使用 M/M/s 结果时可能漏掉什么影响？
6. 午餐时段到达率明显随时间变化，餐厅在 11:00 刚开门时为空。应采用稳态还是瞬态分析？
