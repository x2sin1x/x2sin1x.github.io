# 和声

两个以上的音同时发响并形成可辨认的纵向关系，便构成**和声**。在调性音乐中，和弦的组织常参与旋律伴奏、段落划分和张力塑造；不同风格对和弦、低音和声部连接的理解并不完全相同。

本模块分为两大板块：

- **[古典和声](/knowledge-planet/harmony/classical-harmony/)**：以斯波索宾等人的《和声学教程》为主要参照，从四部和声练习入手，介绍功能和声、和弦连接、终止、离调、转调及变和弦等内容。书中的规则属于特定教学体系，阅读时需结合风格与语境。
- **[流行和声](/knowledge-planet/harmony/pop-harmony/)**：结合级数记谱和歌曲写作，介绍常见进行、七和弦与扩展音、低音设计、副属和弦、借用和弦与转调。示例用于说明常见选择，不代表流行音乐只有这些套路。
