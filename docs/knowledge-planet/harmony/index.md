# 和声

两个以上的音按一定规律同时发响，便构成**和声**。如果说旋律是音乐的横向线条，那么和声就是音乐的纵向结构——它为旋律提供支撑，赋予音乐以色彩、张力与方向感。

本模块分为两大板块：

- **[古典和声](/knowledge-planet/harmony/classical-harmony/)**：以斯波索宾《和声学》教材体系为主线，从四部和声写作入手，系统梳理功能体系和声——正三和弦、七和弦、转位、终止式、离调与转调、变和弦与持续音等核心内容。
- **[流行和声](/knowledge-planet/harmony/pop-harmony/)**：结合现代流行音乐的实践，梳理以级数体系为基础的和声理论——常用和弦进行、七九和弦与加音挂留和弦、低音设计、副属与二五进行、调式互换与转调手法等。
