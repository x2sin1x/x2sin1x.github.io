# 七和弦与九和弦

三和弦之外，流行音乐最常用的纵向材料是七和弦与九和弦。在三和弦上再叠置一个三度得到**七和弦**，叠置两个得到**九和弦**。它们的共同特征是不协和：七音与根音的七度关系使和弦内部产生张力，从而获得三和弦没有的**色彩**与**倾向**。流行音乐对不协和的态度与古典不同——不协和不必立刻解决，常常被当作一种"风味"长期保持。

## 四种常见七和弦

按三度叠置的四个音，两两之间的音程组合决定了七和弦的性质。流行中最常用的是以下四种：

| 名称 | C 大调示例 | 构成（根音起） | 色彩 |
| :--: | :--: | :--: | :--: |
| 大七和弦 | Cmaj7 | 大三度+小三度+大三度 | 柔和、朦胧、爵士感 |
| 属七和弦 | C7 | 大三度+小三度+小三度 | 强烈、外倾、要求解决 |
| 小七和弦 | Cm7 | 小三度+大三度+小三度 | 柔和内敛，小调的三和弦+色彩层 |
| 半减七和弦 | Cm7-5（Bm7-5 型） | 小三度+小三度+大三度 | 阴暗、悬置、待解决 |

注意大七与属七的区别只在七音：E 上方的大七度 B 使和弦朦胧发亮，小七度 Bb 则立刻让和弦变得"急切"。小七和弦可以理解为小三和弦叠一个纯五度下方的大六度，也可以理解为它的高声部"暗藏"着一个大六和弦——这正是流行中 Cm7 与 Cm6 可互相替代的原因。

## 大调各级自然七和弦

与三和弦一样，大调七个音级上的七和弦性质也是固定的，无需记忆每个和弦，只需记住分布模式：

| 级数 | C 大调 | 性质 |
| :--: | :--: | :--: |
| 1 | Cmaj7 | 大七 |
| 2m | Dm7 | 小七 |
| 3m | Em7 | 小七 |
| 4 | Fmaj7 | 大七 |
| 5 | G7 | 属七 |
| 6m | Am7 | 小七 |
| 7m-5 | Bm7-5 | 半减七 |

## 九和弦与 add9 的区别

**九和弦**是在七和弦之上再叠一个三度（根音上方大九度，即高八度的二音），它包含五个音：

- C9（属九）= C E G Bb D，在属七的基础上加九音，张力更大、层次更厚，常用于 5 级的属位置（G9）与布鲁斯语汇；
- Cmaj9 = C E G B D，大七+九音，是爵士抒情段的代表性色彩。

**add9** 则完全不叠七音，只是三和弦直接加一个九音：Cadd9 = C E G D。它与 C9 的区别关键在于**有没有七音**——没有七音，就没有属七的解决要求，add9 是纯粹的色彩加厚，可以像三和弦一样自由使用。Cadd9 的四个音恰好是一把开放把位吉他最顺手的四个音，这使它在吉他驱动的流行歌曲中出现频率极高。

## 内声部下行的柔化技巧

七和弦在流行中最经典的用法之一，是让**三和弦 → 加七音/去五音的链式交替**产生内声部级进下行。C 和弦在延续中依次变为 Cmaj7、C6：

- C（C E G）→ Cmaj7（C E G B）：五音 G 保持，新加的七音 B 从上方落进内声部；
- Cmaj7（C E G B）→ C6（C E G A）：七音 B 半音下行到六音 A。

上方的旋律声部不动，内声部 E-G-B-A 依次滑落，和声名称在变而和弦归属未变，是最经济的"一个和弦讲两句"的手法。若把 C6 理解为 Am7 的转位（A C E G），这条链还暗含主和弦向 6m 渐变的色彩转移。

## 属七的弱化倾向

古典和声中，属七是不折不扣的"必需品"——D7 及其转位是终止的标配（见[属七和弦及其转位](/knowledge-planet/harmony/classical-harmony/属七和弦及其转位)）。流行音乐却大量出现属七的**弱化形态**：

- 用 **5（大三和弦）** 代替 57：干干净净的三和弦终止，避开属七的急切感；
- 用 **5sus4 → 5**：挂留音先"迟到"解决，属和弦的导音倾向被推迟半拍；
- 用 **2m7-5** 或 **5/7（转位属七）**：把属七的功能拆到低音线或回转中，详见[副属和弦与二五进行](/knowledge-planet/harmony/pop-harmony/副属和弦与二五进行)。

弱化的原因是审美性的：属七的半音强倾向会打断流行的循环感与旋律的吟唱性，流行和声宁可让回家的动作更从容。这与[古典和声](/knowledge-planet/harmony/classical-harmony/)严格维护 D—T 力度的取舍恰好相反，理解这一点就理解了两个体系气质的分野。

## 各级七和弦的惯用位置

自然七和弦在流行中的分布不是均匀的，以下位置最常见：

- **1maj7**：开头与结尾的柔化落点；结尾处 1maj7 比 1 更“收得住”而少一份终止的断然；
- **4maj7**：大调中最好听的下属七和弦，F-Fmaj7 式的同根音微调是定调色的常用动作；
- **2m7**：几乎总是以回转成员身份出现（2m7-57-1 或 6m-2m7-57-1）；
- **6m7**：小调侧的柔化，6m-5 的直线可以被 6m7-5 或 6m7-4maj7 的曲线取代；
- **3m7 与 7m-5**：3m7 常作 6m 前的过渡；7m-5 主要出现在通往 6m 的过渡（7m-5 与 V7/vi 或 3m 配合，见[副属和弦与二五进行](/knowledge-planet/harmony/pop-harmony/副属和弦与二五进行)）。

## 半减七的出场场景

m7-5（Bm7-5 型）在流行中有两类典型位置：一是爵士回转中 2m7 的“变暗版”（2m7-5-57-1，源自小调 ii-V 语汇）；二是作为通往 6m 的楼梯：7m-5 与 3m、V7/vi 同属“指向 6m”的家族，7m-5-6m 的低音 B→A 级进下行配合内声部导音解决，比直接 5-6m 的假终止更含蓄。

## 小结

- 七和弦因含不协和的七度而获得色彩与倾向；四种常用七和弦是 maj7、7、m7、m7-5，区别在于音程叠加组合。
- 大调自然七和弦的分布：1、4 大七，2、3、6 小七，5 属七，7 半减七；任何级数进行都可整体七和弦化。
- 九和弦含七音、有张力层次；add9 不含七音，是纯色彩加厚，可自由使用。
- C—Cmaj7—C6 链式交替产生内声部级进下行，是"一个和弦延续两句"的经典技巧。
- 流行音乐倾向弱化属七（用三和弦、sus、回转替代），这与古典维护 D—T 强解决的取向构成体系气质的核心差异。
