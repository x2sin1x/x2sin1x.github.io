# 副属和弦与二五进行

调内的七个自然和弦虽然够用，但色彩终究有限。流行和声增加色彩的第一手段，是把每个自然和弦都临时当作"主和弦"，在它前面放上它自己的属和弦——这就是**副属和弦**。它带来的临时偏移让进行瞬间摆脱"调内味"，是流行与爵士和声最有表现力的扩张工具之一。古典体系中对应的技术是离调，见[重属和弦与离调](/knowledge-planet/harmony/classical-harmony/重属和弦与离调)。

## 副属和弦：V7/x

在 C 大调中，5（G7）之所以有强烈的回家倾向，是因为它包含导音 B 与三音 F 构成的三全音。给任何其他级数套用同样的"属七结构"，就得到副属和弦，记作 **V7/x**（读作"以 x 为临时目标的属七"）：

- **V7/IV = C7**：目标 4（F），临时"属音"是 C 大调的 1 音；
- **V7/V = D7**：目标 5（G），临时导音是 F#；
- **V7/vi = E7**：目标 6m（Am），临时导音是 G#；
- **V7/ii = A7**：目标 2m（Dm），临时导音是 C#；
- **V7/iii = B7**：目标 3m（Em），较少用。

```abcjs
X: 1
T: 副属和弦：1—C7(V7/IV)—4 — 1—D7(V7/V)—5
M: 4/4
L: 1
K: C
[C,EGc] | [C,EG_B] | [F,ACf] | [C,EGc] | [D,^FA] | [G,BDg] ||
```

副属和弦的结构特征是：它一定含有一个**调外音**（目标和弦根音上方四度的三音，即临时导音），这个半音倾向就是推动力的来源。V7/x → x 的解决是根音下行五度（上行四度）的强进行加导音半音解决，双重倾向叠加，效果干脆有力。

三个最常用的位置有固定的惯用语境：

- **1 — V7/IV — 4**：让 4 的出现获得冲击，常用于副歌的开头；
- **4 — V7/V — 5**：通往属和弦前的加速，重属方向的流行形态；
- **5 — V7/vi — 6m**：把本应回家的 5 "骗"向 6m，制造假终止式的转折，情绪骤暗。

## ii-V：功能的浓缩

**ii-V（2m7—57）**是爵士和声的核心单元，最终解决到 1：**2m7-57-1**（Dm7-G7-Cmaj7）。它是古典终止式（S—D—T，见[终止式](/knowledge-planet/harmony/classical-harmony/终止式)）的**功能浓缩**：2m7 同时携带下属色彩（含 4 音）与属前驱地位，57 完成导音解决，两个和弦走完整个 T—S—D—T 循环。

```abcjs
X: 1
T: 2m7—57—1（Dm7—G7—Cmaj7）
M: 4/4
L: 1
K: C
[D,FAC] | [F,GBD] | [C,EGB] ||
```

ii-V 强大之处在于它的**模块性**：任何和弦前都可以放上"它自己的 ii-V"，如 G 前放 Am7-D7（= ii-V/V），F 前放 Gm7-C7（= ii-V/IV）。整条进行因此可以不断自我加链，形成爵士即兴的进行网。副属和弦 V7/x 与 ii-V/x 的区别只是"是否带上临时的 ii"——二者是同一逻辑的繁简两式。

## 流行中的柔化用法

爵士的 ii-V 力度强劲，流行歌曲常把它柔化后嵌入：

- 只取 **2m7—5** 而解决到 1 的三和弦或 1add9（去掉爵士的九音收尾）；
- 用 **2m7—5/7（转位）** 让低音 2→5→1 或 2→7→1 保持级进；
- 把 ii-V 放在**弱拍**或过渡小节，作为段落的"回转弹簧"而非终止；
- 6m-2m-5-1 的长链回转（见[常用和弦进行](/knowledge-planet/harmony/pop-harmony/常用和弦进行)）本质是四个连续下五度解决的模块化拼接。

## 三全音替代：subV

**三全音替代（tritone substitution）**是指用距离目标同样"半音之遥"的另一个属七替换 V7：用 **bII7 替代 V7**。C 大调中即用 **Db7 替代 G7**：

- G7 与 Db7 共享同一个三全音（B—F 与 F—Cb 等音），对目标的解决倾向完全相同；
- 区别在低音：G7→C 低音上行四度，Db7→C 低音下行半音。

三全音替代的最大价值是**低音的半音下行**：**Dm7—Db7—Cmaj7** 中低音 2→b2→1 级进滑落，平滑而慵懒，是爵士与拉丁风流行终止的经典形态。记作 **subV7** 或 bII7，古典变音体系中的那不勒斯和弦（见[变音体系与变和弦](/knowledge-planet/harmony/classical-harmony/变音体系与变和弦)）与它共享同一位低音邻居。

```abcjs
X: 1
T: 三全音替代：2m7—subV7—1（Dm7—Db7—Cmaj7）
M: 4/4
L: 1
K: C
[D,FAC] | [_D,F,_A,C] | [C,EGB] ||
```

## 连续副属与五度圈链

副属和弦可以串联使用：给每个目标再配一个它自己的属七，形成连续的下五度解决链。例如 **3m—V7/vi—6m—V7/ii—2m—V7/V—5**：每一步都在“新目标前先竖起它的属和弦”，五度圈力量层层推进，是爵士与放克中常见的动力化段落。在流行歌曲中，通常只取链条的后两环（如 2m—57—1）并柔化，见下节。

```abcjs
X: 1
T: 五度圈链：E7(V7/vi)—Am—A7(V7/ii)—Dm—D7(V7/V)—G
M: 4/4
L: 1
K: C
[E,G#,B,d] | [A,CE] | [A,C#E,G] | [D,F,A] | [D,^FA,c] | [G,B,D] ||
```

## 假终止与副属的联用

5—V7/vi—6m 的假终止（上文第三种惯用语境）之后，通常接 4 或 2m 重新起步，再走 5—1 完成真正的回家。“骗一次，再认真收”的两段式收尾比一次到位更有叙事感：

```abcjs
X: 1
T: 假终止后重新收束：5—E7—6m—2m—5—1
M: 4/4
L: 1
K: C
[G,B,D] | [E,G#,B,d] | [A,CE] | [D,F,A] | [G,B,D] | [C,E,G] ||
```

## 与古典离调体系的对应

副属和弦与古典离调是同一件事的两种表述，差异在使用密度与解决纪律：

- 古典离调受四部和声规则约束，副属和弦的导音必须严格解决，离调深度受段落功能控制；
- 流行与爵士把 V7/x 当作自由插件，甚至允许不解决（如 E7 直接接回 F 或 Ab，靠音响自洽）；
- 古典的重属和弦 DD（V/V、DDVII）对应流行最常用的 V7/V 与 ii-V/V 位置。

理解了这层对应，[古典和声](/knowledge-planet/harmony/classical-harmony/)中关于离调的分析工具可以直接搬到流行歌曲的和声分析上。

## 小结

- 副属和弦 V7/x 是把目标和弦临时当作主和弦、在前面放置它的属七；调外导音的半音倾向是推动力来源。
- 常用位置：1-V7/IV-4、4-V7/V-5、5-V7/vi-6m；最后一个制造假终止式转折。
- ii-V 是古典 S—D—T 的功能浓缩，具模块性，任何和弦前都可以套用它的 ii-V。
- 三全音替代用 bII7 换 V7，共享同一三全音，价值在于 subV-1 的半音下行低音线。
- 副属和弦与古典离调同源；流行用法更自由，解决纪律放宽，但分析工具互通。
