# 加音与挂留和弦

在三和弦与七和弦之外，流行和声还有一组不按三度整齐叠置的"自由加音"材料：add 和弦、sus 和弦、六和弦与强力和弦。它们的共同特征是**不改变和弦的功能归属**，只在色彩层面作加法或替换，是编配中调整质感的第一顺位手段。

## add 和弦：加音和弦

**add（added-tone chord）**记法表示在三和弦上直接附加指定的音，但**不加七音**。最常见的是 add9：

- **Cadd9 = C E G + D**（九音即高八度的二音）。二音与三音相邻叠置产生的轻微不协和带来"蓬松、明亮"的现代感；
- **Cadd2 = C D E G**，与 add9 音相同、排列不同：add9 的九音排在三音之上，add2 的二音插在三音之下，二者常可通用，add9 更通行；
- **Cadd11 = C E G + F**。四音与三音是二度关系，不协和明显，add11 多与 sus4 音响趋同，使用频率远低于 add9。

::: abcjs
X: 1
T: C — Cadd9 — Cadd2
M: 4/4
L: 1
K: C
[C,EG] | [C,EGd'] | [C,D,EG] ||
:::

add9 之所以比加七音更"安全"，是因为它保留了三和弦的干净骨架，没有七度不协和，也就没有解决要求。在三和弦已经稳定的段落里，add9 是代价最小的加厚。

## sus 和弦：挂留和弦

**sus（suspended）**记法表示用二度音替换三度音，和弦因此**失去三音**——大小性质被抹去，处于"既不大也不小"的中性状态：

- **Csus4 = C F G**：四音 F 替换三音 E；
- **Csus2 = C D G**：二音 D 替换三音 E，与 sus4 音响相近但更开阔。

::: abcjs
X: 1
T: Csus4 — C 的装饰解决
M: 4/4
L: 1
K: C
[C,FG] | [C,EG] ||
:::

sus 和弦的独特倾向来自**挂留音的下行二度解决**：sus4 的四音天然倾向于落回三音（F→E）。这一倾向源自古典对位法中的挂留处理，但在流行中通常不写"解决"的分析，而是直接把 **Xsus4 → X** 当作一个装饰性动作：属和弦前的 **5sus4-5** 延迟导音的出现，使回家的一步更从容；同一个和弦内部的 **1sus2-1** 则制造微小的呼吸感。

与 add11 的区别在于：sus4 是**替换**（三音不出现），add11 是**叠加**（三音与四音并存），后者不协和得多。

## 六和弦：C6 与 add6

**六和弦**（此处指 C6 = C E G A，即大三和弦加纯五度下方的大六度音）与七和弦系列并立：

- C6 与 Cadd6 同义，六个音上加六音，色彩怀旧、明亮，常见于爵士与老歌的结尾替代 C 本身；
- C6 与 **Am7（A C E G）** 是同音异名关系：同一组音，低音在 C 时听作 C6，低音在 A 时听作 Am7。这提醒我们六和弦带有隐含的小调色彩；
- 小六和弦 **Cm6 = C Eb G A**，在布鲁斯与小调爵士中常用来替代 Cm7 的结尾。

::: abcjs
X: 1
T: C — C6 与 Am7 的同音异名
M: 4/4
L: 1
K: C
[C,EGA] | [A,,CEG] ||
:::

## 强力和弦：Power Chord

**Power chord**（5 和弦）只保留根音与五音，**去掉三音**：C5 = C G。因为三音缺席，和弦不分大小，性质完全中性。

::: abcjs
X: 1
T: C5 — G5 强力和弦
M: 4/4
L: 1
K: C
[C,G,] | [G,D] ||
:::

它的意义主要在音响与演奏层面：根音与纯五度的叠加在失真电吉他上不产生三和弦那样的互调失真冲突，音墙干净而有力量，是摇滚与金属和声的基本单元。从和声理论看，power chord 与 sus 和弦同属"无三音"的中性和弦，功能归属由前后文决定——同一个 G5 在 1-5-6m-4 中仍是属功能，在 C5-G5-A5-F5 的平行移动中则只保留级数的骨架而抹平色彩变化。

## 色彩功能的定位

把本篇的材料放到功能框架中定位，有助于在编配时正确选型：

- **加音类**（add9、C6）：不改变功能，只加厚——用于让停顿处的和弦更有质感；
- **挂留类**（sus4、sus2）：抹平大小、制造延迟——用于属和弦前的缓冲与段内装饰；
- **中性类**（5 和弦）：抹去三音、突出骨架——用于摇滚力量化或平移段落。

这些手法与七和弦的柔化技巧（见[七和弦与九和弦](/knowledge-planet/harmony/pop-harmony/七和弦与九和弦)）可以叠加使用：同一条进行，用三和弦、七和弦、add9、sus4 分别染色，就是四段气质不同的编配。

## 同一根音的色彩阶梯

把本篇材料与七和弦串起来，同一根音 C 可以排出一条由素到华的色彩阶梯：C5 → C → Cadd9 → C6 → Cmaj7 → C7。编配时在同一个和声功能位上前后移动半格，就能获得级差极小的色彩呼吸：

::: abcjs
X: 1
T: 同一根音的色彩阶梯：C5—C—Cadd9—C6—Cmaj7
M: 4/4
L: 1
K: C
[C,G,] | [C,E,G] | [C,E,Gd'] | [C,EGA] | [C,EGB] ||
:::

这条阶梯在流行歌曲里最常见的实际运用，是让主歌用素净的 C、副歌用 Cadd9 或 Cmaj7，不换进行只换和弦厚度，段落对比就完成了大半（与[曲式中的和声布局](/knowledge-planet/harmony/pop-harmony/曲式中的和声布局)的段落策略直接对接）。

## 与低音设计的配合

挂留与转位可以叠加：**G/B 后接 Csus4-C**（低音 B-C 级进上行的同时，C 和弦内部四音 F 解决到三音 E），低音线与挂留解决两层动作同时完成，是键盘编配里手感与听感都极佳的连接。反过来，power chord 段落内低音往往由吉他与贝斯同度或八度重叠，转位几乎不出现——无三音的和弦让低音设计的余地让位给节奏设计。

## 小结

- add 和弦在三和弦上附加音级但不加七音，无解决要求；add9 明亮蓬松，add11 与 sus4 音响趋同而少用。
- sus 和弦用二度音替换三音，抹去大小性质，挂留音有下行二度解决倾向；Xsus4-X 是最常用的装饰动作。
- C6 与 Am7 同音异名，六和弦色彩怀旧，常作结尾替代。
- Power chord 只留根音与五音，三音缺席使其中性，是失真电吉他与摇滚和声的基础。
- 加音、挂留、强力和弦都不改变功能归属，只在色彩层面工作；选型的依据是段落需要的质感与张力。
