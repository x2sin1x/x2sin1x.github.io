# 调式互换与借用和弦

自然大调的和弦库只有七个，当编配需要更复杂的情绪层次——悲壮、怀旧、史诗感——时，最有效的来源是**平行调**：同一个主音上的小调式。从平行小调（或平行调式）中把和弦"借"到大调中使用，称为**调式互换（modal interchange）**，借来的和弦称**借用和弦（borrowed chord）**。它是流行和声色彩系统中最具情感杀伤力的一族。古典体系中对应的技术是同主音大小调交替，见[和声大调与副三和弦](/knowledge-planet/harmony/classical-harmony/和声大调与副三和弦)。

## 调式互换的概念

C 大调与 c 小调共享同一个主音 C，但音阶中的三、六、七级不同。把小调的各级和弦整体搬到 C 大调的进行中，就得到一组以 **bIII、bVI、bVII、iv、bm-5** 为代表的新和弦。它们的功能归属仍然围绕 C 主音（大多仍是"离开家"或"回家的变体"），但带着明显的小调阴影。

"互换"是双向的：大调可以借小调的 iv、bVI，小调也可以借大调的 IV、VII（多利亚色彩）。本篇以大调借用为主线。

## C 大调的常用借用和弦

| 借用和弦 | 构成 | 来源 | 色彩关键词 |
| :--: | :--: | :--: | :--: |
| bIII | Eb（bE G bB） | 平行小调 3 级 | 开阔、摇滚 |
| bVI | Ab（bA C bE） | 平行小调 6 级 | 悲壮、宽广 |
| bVII | Bb（bB D F） | 平行小调 7 级 | 混合利底亚、史诗 |
| iv | Fm（F bA C） | 平行小调 4 级 | 哀伤、怀旧 |
| bm-5 | Bm7-5（B D F A） | 平行小调 2 级 | 阴暗、爵士 |

### bVII：混合利底亚的旗帜

**bVII（Bb）**是借用和弦中的头号常客。它到 1 的进行 bVII—1 是"变体属进行"——没有导音 B 的半音拉力，却有下五度落点的方向感，回家回得"稳"而不"急"。**1—bVII—4—1** 这样的循环使大调带上混合利底亚（Mixolydian）调式的味道，是摇滚、放克与史诗感片头曲的标配。bVII 也常与 bVI、bIII 连用：**bVI—bVII—1**（Ab—Bb—C）的低音级进上行是"凯旋式结尾"的经典语汇。

### 小调 iv：一滴眼泪

**iv（Fm）**只含一个调外音 bA，但效果惊人。它通常插在 4 或"4—5—1"的位置附近：

- **iv—1**：变格终止的小调化，结尾处 Fm→C 让大调瞬间蒙上阴影再落定，怀旧感极强；
- **1—iv—1**：和弦内部的一滴眼泪，常见于叙事型歌词段；
- **iv—bVII—1** 或 **iv—5**：在小调化之后再决定是否回家。

与 **4maj7（Fmaj7）** 相比，**iv（Fm）**是把同位置的下属功能调暗：4maj7 温暖明亮，4m 苍凉内收。编配时在 4 的位置"选亮还是选暗"，是情绪定调的直接开关——同一段落 4 与 4m 交替出现（如 "F—Fm—C"），则获得大小明暗的对答。

### bIII 与 bVI

**bIII（Eb）**是"远处的主和弦"：它距主音为小三度，音响开阔，常与 bVI、bVII 组成平行小调的 1—bVI—bIII—bVII 移植块（见下文），或单独以 bIII—bVI—bVII—1 的进行制造大开大合的段落转折。**bVI（Ab）**到 1 是小三度下行的"叹息落点"，bVI 前常垫 V7/vi 或直接从 1 跳入。

## 平行块的移植

调式互换最强力的用法不是零星借用，而是**整块移植**：把平行小调的一条进行整体搬进大调段落。以小调侧经典的 **bVI—bVII—1** 与 **1—bVI—bIII—bVII** 为代表：

- **1—bVI—bIII—bVII**（C—Ab—Eb—Bb）：这一循环在大调中展开时，主和弦 C 是唯一的大调立足点，其余全部来自平行小调，明与暗的对峙形成史诗般的张力，常见于副歌的最高潮段落；
- **bVI—bVII—1**（Ab—Bb—C）：低音 b6—b7—1 级进上行，三层渐强的凯旋感。

M: 4/4

## bm-5 的用法

**bm-5（Bm7-5 型）**在借用家族里戏份最少但位置独特：它是平行小调的 2 级，天然指向平行小调的 5（小调属）或直接回到 3m。在大调段落中，它主要承担两个角色：

- 作为通往 6m 的爵士化楼梯（与 3m、V7/vi 同族，见[七和弦与九和弦](/knowledge-planet/harmony/pop-harmony/七和弦与九和弦)）；
- 作为小调化预副歌的起点：bm-5—5 或 bm-5—57—1 的回转把张力压得更暗更紧。

由于三音 B、五音 F 都在大调之内，它比其他借用和弦“混血”得更自然，是初学借用时的安全选择。

## 借用与终止的互动

借用和弦进入终止式时有一组惯用搭配：

- **bVII—1**：无导音的沉稳收束，与 5—1 并列的变体终止；
- **bVI—bVII—1**：低音 b6—b7—1 级进上行的凯旋收束；
- **iv—1**：变格终止的小调化（对应古典的变格终止，见[终止式](/knowledge-planet/harmony/classical-harmony/终止式)）；
- **bVI—5—1**：bVI 先“叹息”下行，再由真属和弦收束，兼得两种色彩。

```abcjs
X: 1
T: bVI—bVII—1 的凯旋收束与 iv—1 的变格收束
M: 4/4
L: 1
K: C
[_A,C,_E] | [_B,D,F] | [C,E,G] | [F,_A,C] | [C,E,G] ||
```

## 与古典体系的对应

古典和声中，同主音大小调的交替和弦（同主音小调的 bVI、bVII、bIII 等）与[和声大调](/knowledge-planet/harmony/classical-harmony/和声大调与副三和弦)的 bVI 级同属变音交替体系，其解决纪律（导音解决、增音程处理）有严格规定；流行用法几乎不设纪律，借用和弦可以像自然和弦一样自由进出。值得注意的是，古典的**变格终止**（4—1）在流行中由 **iv—1** 或 **4maj7—1** 承接，见[终止式](/knowledge-planet/harmony/classical-harmony/终止式)。

使用借用和弦时的实用原则：

- 一次只借一个功能位（尤其在叙事段），整块移植留给高潮；
- 借用和弦中的调外音最好由旋律或内声部级进引入、级进出，避免生硬跳出；
- bVII 之后避免直接接 5（两个属方向打架），若需接 5，中间垫 4 更顺。

## 小结

- 调式互换从平行调借入和弦，最常见的来源是平行小调；借入的和弦功能仍围绕同一主音。
- C 大调的四大借用：bIII 开阔、bVI 悲壮、bVII 史诗（混合利底亚）、iv 哀伤；bm-5 供阴暗过渡。
- iv 与 4maj7 是同位置下属功能的一暗一亮，"F—Fm—C"式明暗对答是定调的直接开关。
- 整块移植（1—bVI—bIII—bVII、bVI—bVII—1）制造史诗级高潮；零星借用适合叙事段。
- 与古典同主音交替同源，流行不设解决纪律；调外音宜级进引入，bVII 后避免直接接 5。
