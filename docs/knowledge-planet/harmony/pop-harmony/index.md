# 流行和声

流行和声与古典和声共享同一套声学与功能逻辑的根基，但在记谱习惯、进行逻辑与色彩运用上有自己的一套体系：它以**级数**（1~7）而非功能字母思考和弦，大量使用七和弦、加音与挂留和弦来制造色彩，并发展出 4536251、卡农进行等高度程式化的进行语汇。

本板块侧重**理论体系**：先建立级数体系与流行功能观，再逐一拆解常用进行、七九和弦、加音挂留、转位与低音设计、副属与二五进行、调式互换与转调手法，最后落到曲式中的和声布局。编配实操与具体歌曲的完整分析可在掌握本板块后自行延伸。

记谱约定：文章中同时使用**级数标记**（如 1-5-6m-4，小写 m 表示小三和弦）与**字母和弦标记**（如 C-G-Am-F），谱例默认以 C 大调呈现，便于直接在钢琴上对照。
