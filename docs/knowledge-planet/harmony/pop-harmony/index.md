# 流行和声

流行和声可以使用级数、和弦字母或罗马数字来描述。级数和弦表便于移调，和弦字母便于演奏沟通，罗马数字便于观察调性功能；这些记谱方式各有用途，并不能简单归结为流行与古典的绝对分界。七和弦、加音与挂留和弦、循环进行等，都是本板块会介绍的常见材料。

本板块侧重基础概念与写作选择：先建立级数体系，再讨论常见进行、七和弦与扩展音、转位与低音设计、副属与二五进行、调式互换和转调，并联系段落布局。谱例多为简化的和弦示意，不等同于完整歌曲编配。

记谱约定：文章中同时使用**级数标记**（如 1-5-6m-4，小写 m 表示小三和弦）与**字母和弦标记**（如 C-G-Am-F），谱例默认以 C 大调呈现，便于直接在钢琴上对照。
