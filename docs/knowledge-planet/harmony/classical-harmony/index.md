# 古典和声

本板块以斯波索宾等所著《和声学教程》（Дубовский、Евсеев、Способин、Соколов 合著）的章节体系为主线，将其六十余章的内容合并梳理为十三讲，覆盖从四部和声写作基础到变音体系与转调的完整脉络。

和声学习的两条主线是**理论**（和弦结构与功能逻辑）与**写作**（四部和声的声部进行规则）。建议边读边在五线谱上动手练习：为给定旋律配和声、分析和声片段，是掌握本章内容的必经之路。

记谱约定：功能标记采用斯波索宾体系，主功能记作 **T**，下属功能记作 **S**，属功能记作 **D**，罗马数字表示级数（大写为大三和弦类，小写为小三和弦类），转位用数字低音标记（6、46、65、43、42 等）。
