# 绪论与四部和声

若干个音按照一定的规律同时发响并组织起来，便构成**和声**。研究和弦的结构、和弦之间的连接规律以及它们在音乐作品中表现作用的学问，称为**和声学**。如果说[旋律](/knowledge-planet/music-theory/)是音乐的横向线条，那么和声就是音乐的纵向结构：它为旋律提供支持，形成音乐的力度涨落与色彩变化，并参与音乐曲式的构成。

学习古典和声，采用**四部和声**作为基本的写作体裁。这不只是一种练习格式——自巴赫以来的整个功能和声体系，都是在四声部合唱织体中形成和提炼的。掌握四部和声的写作规则，就掌握了功能和声的核心语法。

## 三和弦与七和弦

和声学的材料是[和弦](/knowledge-planet/music-theory/和弦)。这里简要回顾其结构，作为后续章节的基础。

### 三和弦

按三度关系叠置的三个音构成**三和弦**，自下而上分别称为**根音**、**三音**与**五音**。三和弦分为大三和弦、小三和弦、增三和弦与减三和弦四种，其中大、小三和弦是协和和弦，增、减三和弦是不协和和弦。

### 七和弦

在三和弦之上再叠置一个三度音，构成**七和弦**，第四个音称为**七音**。常用的七和弦有大七和弦、大小七和弦（属七）、小七和弦、半减七和弦与减七和弦。一切七和弦都是不协和和弦——七音与根音之间的七度音程（或其转位二度）总是不协和的，这决定了七和弦必须"解决"，也是和声张力的主要来源之一。

## 四个声部

四部和声的四个声部沿用混声合唱的名称与音域，自高至低为：**女高音**（Soprano）、**女低音**（Alto）、**男高音**（Tenor）、**男低音**（Bass）。其中女高音声部常担任旋律，也称**旋律声部**；男低音声部决定和弦的低音，是和声功能的基石；女低音与男高音位于中间，称**内声部**，女高音与男低音合称**外声部**。

| 声部 | 名称 | 大致音域 |
| :--: | :--: | :------: |
| 女高音 | S | 小字一组 c — 小字二组 a |
| 女低音 | A | 小字组 g — 小字二组 d |
| 男高音 | T | 小字组 c — 小字一组 g |

记谱时，女高音与女低音记在高音谱表上（女低音符干朝下），男高音与男低音记在低音谱表上（男高音符干朝上）。各声部超出音域是四部和声写作中最常见的基本错误之一，必须避免。

## 排列法

同一个三和弦在四个声部中的分布方式称为**排列法**。区分排列法，只看上方三个声部（女高音、女低音、男高音）中相邻两声部之间的距离：

- **密集排列**：相邻的上方声部之间的距离为三度或四度，即相邻两声部之间插不进该和弦的其他和弦音。音响紧凑而集中。
- **开放排列**：相邻的上方声部之间的距离为五度至八度，即相邻两声部之间可以插入一个该和弦的和弦音。音响开阔而均衡。

无论采用哪种排列法，相邻的上方声部之间的距离都不得超过八度；而男低音与男高音之间的距离可以超过八度，甚至达到两个八度，因为低音区音程过密反而会使音响浑浊。

## 重复音原则

四部和声只有四个声部，而三和弦只有三个音，因此必有一个音在两个声部中重复。**重复音**的选择直接影响音响的丰满与协和：

- 原位三和弦一般**重复根音**，这是最自然、最常用的方式，因为根音是和弦的基础；
- 重复五音也可以使用，常出于声部进行的需要；
- **三音一般不重复**：三音决定和弦的大小色彩，重复后或显生硬（大三和弦），或显暗淡（小三和弦）。但在减三和弦中，由于减五度音程的倾向性，反而常常重复三音；
- 七和弦有四个不同的音，原则上**不重复任何音**；当声部安排需要省略音时，通常省略五音而**重复根音**。

## 写作的基本规范

在动手写作之前，先确立几条贯穿全书的基本规范：

1. **音域**：每个声部都不得超出自己的音域，也不能长时间停留在音区极限上。
2. **声部交叉**：较低声部的音不得高于相邻较高声部正在演唱的音（如男高音不得高于女低音）。写作进行中还要防止**声部超越**——即某声部进行后的音高于（或低于）另一声部的前一个音，造成声部线条的交错混乱。
3. **声部进行**：单个声部从一个音到下一个音的横向运动称为**声部进行**。级进（二度）与三度以内的平稳进行是基本方式；四度以上的**跳进**要有节制，并在跳进之后以反向级进缓和地解决。
4. **节奏关系**：四个声部原则上使用相同的节奏（一音对一音），和声节奏（换和弦的频率）应当与乐曲的节拍结构相协调，这将在后续章节中详细讨论。
5. **不良进行**：平行五度、平行八度等破坏声部独立性的进行被严格禁止，详见[下一讲](/knowledge-planet/harmony/classical-harmony/原位三和弦与和声进行)。

这些规则的目的并非束缚，而是保证四个声部各自线条清晰、纵横两方面的音响都协调丰满。古典和声的写作训练，正是在这纵横两个维度的平衡中展开的。

## 小结

- 和声学研究和弦的结构、连接规律与表现作用；功能和声体系以四部和声为基本写作体裁。
- 三和弦由根音、三音、五音构成；七和弦再加七音，均为不协和和弦，需要解决。
- 四个声部沿用合唱名称：女高音、女低音、男高音、男低音，各有确定的音域，不得超越。
- 排列法分密集与开放两种，以上方三个声部相邻两声部的距离划分；上方相邻声部间距不得超过八度。
- 原位三和弦一般重复根音，三音一般不重复；七和弦原则上不重复音，需要时省五音重复根音。
- 写作须遵守音域、声部交叉、声部超越等基本规范，并以平稳的声部进行为基础。
