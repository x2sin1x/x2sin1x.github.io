# 三和弦的转位

原位三和弦以根音为低音。当三音或五音处于低音部时，便形成三和弦的**转位**：以三音为低音的**六和弦**（第一转位，数字低音记作 6），以五音为低音的**四六和弦**（第二转位，数字低音记作 46）。数字的来源是低音与上方和弦音之间形成的音程——六和弦中低音与根音相距六度，四六和弦中低音与根音、三音分别相距四度与六度。

转位和弦改变了低音的位置，却不改变和弦的功能：I6 仍是主功能，V6 仍是属功能。转位使低音部线条摆脱了只沿根音跳动的生硬，得以形成级进的、歌唱性的旋律，这是功能和声低音写作的关键手段。

## 六和弦

### 结构与重复音

六和弦的三音位于低音部，根音与五音在上方三声部中。由于低音已是三音，上方声部通常**重复根音**（也可重复五音），一般不再重复三音，以保持低音三音的独立清晰。

```abcjs
X: 1
T: 六和弦：I6 与 IV6
M: 4/4
L: 1
K: C
[C,EGc] | [A,CFc] | [G,BDb] ||
```

第二个和弦为 IV6（F 大三和弦，低音为三音 A），上方重复了五音 C；第三个和弦为 V6（G 大三和弦，低音 B）。

### 连接规则

六和弦的连接在遵守基本规则之外，还有几条特别的要求：

- **低音部与任何一个上方声部之间的距离不超过八度**：六和弦低音（三音）与根音只差三度，若距离过远，根音会显得脱离和弦整体；
- **避免平行五度与平行八度**：转位并没有豁免权，尤其是低音部级进时，上方声部反向进行最为安全；
- **六和弦可与原位和弦自由连接**：同一功能和弦的转位连接（如 I—I6）按同和弦转换处理，共同音保持，其余声部平稳移动。

### 应用

六和弦最常用于**美化低音线条**：将原位进行中连续的四、五度跳动改为级进或三度进行。例如 I—I6—IV 的低音为 C—E—F，呈级进上行，远比 C—F 的直接跳动流畅。此外，六和弦也常用于结构内部以减弱终止感，使和声持续向前运动。

## 四六和弦

### 结构与重复音

四六和弦的五音位于低音部。与六和弦不同，四六和弦上方声部必须**重复低音（即五音）**——重复根音或三音都会造成不稳定甚至错误的音响。这是因为四六和弦在功能上并不独立：它的低音（五音）才是听觉上真正的支撑音，重复低音可以巩固这一支撑。

四六和弦因此是一种**依附性**的和弦：它总是"寄居"在前后更强有力的和声进行之中，并受严格的节拍条件限制——除终止四六和弦外，一般处于弱拍或弱的位置，低音以级进引入和解决。

### 经过性四六和弦

低音部作级进上行或下行经过时，中间的音配以四六和弦，形成**经过性四六和弦**。典型形式为 T—D46—T6：低音 C—D—E，中间的 D 音（属和弦的五音）以四六和弦形式经过。

```abcjs
X: 1
T: 经过性四六和弦 T—D46—T6
M: 4/4
L: 1
K: C
[C,G,CE] | [D,GBD] | [E,GCC] ||
```

低音部 c—d—e 级进上行；D46 处于弱位，其上方声部平稳连接到 T6，女高音下行二度进入，避免了与低音的平行八度。

### 辅助性四六和弦

低音部保持不动（或作下方助音式往返），前后为同一和弦、中间夹一个四六和弦，形成**辅助性四六和弦**。典型形式为 T—S46—T：低音保持在主音 c 上，中间短暂闪现下属和弦的音响，如同围绕主音的一次和声"装饰"。

```abcjs
X: 1
T: 辅助性四六和弦 T—S46—T
M: 4/4
L: 1
K: C
[C,G,CE] | [C,A,CF] | [C,G,CE] ||
```

三个和弦的低音部都是 c：中间的 S46（F 大三和弦第二转位）重复低音 c，两侧为主和弦，形成低音保持的和声装饰。

### 终止四六和弦

四六和弦中最重要的一种出现在终止处：属和弦之前、以属音为低音的主四六和弦，即**终止四六和弦（K46）**。它在节拍上位于强拍，功能上属于属和声的一部分，是古典终止式的标志性成分。其结构、节拍条件与标准进行详见[第八讲](/knowledge-planet/harmony/classical-harmony/终止式)。

## 小结

- 三音为低音为六和弦，五音为低音为四六和弦；转位不改变和弦的功能。
- 六和弦上方通常重复根音，低音与上方声部间距不超过八度，常用于美化低音线条。
- 四六和弦必须重复低音（五音），具有依附性，处于弱位，由级进低音引入和解决。
- 经过性四六和弦（如 T—D46—T6）出现在级进低音的经过处；辅助性四六和弦（如 T—S46—T）建立在保持的低音上。
- 终止四六和弦 K46 位于强拍、属和声之前，是终止式的核心成分。
