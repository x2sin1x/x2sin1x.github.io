# 重属和弦与离调

功能和声确立调性的手段是"以属支持主"。把这一手段推向调性内部，便得到两件有力的工具：面向属和弦本身的**重属和弦（DD）**，以及面向任何一级和弦的**副属和弦离调**。它们都借用属七和弦的紧张—解决语法，使调性内部的和声进行获得局部的方向感与新鲜色彩。

## 重属和弦（DD）

属和弦（D）的主和弦是"属调"的主和弦，支持它的属功能和弦便是**重属和弦（DD）**——即"属之属"。C 大调中，DD 建立在 II 级音上，并把 III 级音（F）升高半音：DD 大三和弦为 D—F#—A，加上七音 C 即 **DD7**（D—F#—A—C，大小七和弦结构）。

DD 的功能性一望而知：F# 是 D 大调（属调）的导音，强烈倾向属和弦的根音 G。DD 组还包括建立在升 IV 级上的减七和弦 **DDVII7**（F#—A—C—Eb，其中 Eb 来自和声大调的影响），同样解决到 D。

自左至右为 DD 大三和弦、DD7、DDVII7：升 IV 级音 F# 是它们的标志。

### 解决

DD 解决到 D 或 K46：

- **DD—D**：升 IV 级音（F#）上行小二度到属音 G，七音（C，若为 DD7）下行二度到 B，低音上二度（d→g）或保持，进入属三和弦或 D7；
- **DD—K46**：低音进入属音 g，其余声部按倾向解决，K46 再接 D7—T，形成 S—DD—K46—D7—T 的加强终止——这是古典终止式中最华丽的变体之一；
- **DDVII7—K46 / D**：减七和弦的各倾向音收缩解决，低音（升 IV 级）上行到属音。

IV 级和弦之后，DD（升 IV 级 F# 蓄势）在强拍冲向 K46，随即 D7—T 完满收束：与普通的 S—K46—D7—T 相比，多了一层"属之属"的推力。

### DD 的变和弦

DD 还可引入降 VI 级音（与和声大调贯通），形成含**增六度**的变和弦：低音为降 VI 级音，其上方含升 IV 级音，两者构成增六度，向外反向解决到属音八度——这就是所谓**增四六和弦**（德意志增六和弦一类），它以更浓的色彩把和声推向属和弦。其等音结构将在[第十三讲](/knowledge-planet/harmony/classical-harmony/等和弦转调与持续音)中再次出现。

## 离调

调性内的某一和弦（除 I 外）暂时被当作"主和弦"，由它自己的属功能和弦引入，这种局部的、短暂的转调式进行称为**离调**；那些"借来的"属功能和弦称为**副属和弦**，记作 V7/X、VII7/X（X 为目标级和弦）。

离调的语法与转调同源，只是**不建立新调**：副属和弦解决于目标级后，音乐立即回到主调的功能轨道上。最常作为离调目标的是 S 组的各级（II、IV、VI），D 组目标（如 V 的属即 DD）次之，III 亦可。

### 副属和弦的构成

为目标级 X 配属功能和弦，只需站在"X 调"的立场：

- **V7/X**：X 调的属七——以 X 的五度音为根音的大小七和弦，需将音阶中相应的音升高（成为 X 调的导音）；
- **VII7/X**：X 调的导七和弦，以 X 的导音为低音，小调目标的 VII7/X 为减七结构。

C 大调中最常用的几个：V7/II（A7：A—C#—E—G，解决到 II）、V7/IV（C7：C—E—G—Bb，含降 7 级音，解决到 IV）、V7/VI（E7：E—G#—B—D，解决到 VI）。

### 离调的写作要点

1. **副属和弦要解决**：V7/X 必须按七和弦的规则解决到 X（七音下行、临时导音上行到 X 的根音或三音），不可悬置；
2. **临时导音的处理**：升高的音（如 C#）应作上行小二度解决，并尽量出现在同一声部，避免对斜；
3. **离调的节拍与位置**：离调多发生在乐句内部，节拍位置适中即可；乐段的收束仍由主调终止式承担；
4. **回归主调**：离调之后应尽快回到主调的功能进行（常见做法是让目标级以主调中的真实功能身份进入后续和声），避免真正滑入新调。

### 对斜禁忌

离调必然引入变化音。同一音级的变化形式与自然形式若在不同声部紧接出现，即构成**对斜**——例如 C# 与 C 的先后交错。写作时应让变化音与还原音在同一声部作半音进行，或拉开两者的距离。

## 小结

- 重属和弦（DD）是"属之属"：以升 IV 级音为标志，含 DD、DD7 与 DDVII7，解决到 D 或 K46，构成加强终止。
- DD 可引入降 VI 级形成含增六度的变和弦（增四六和弦），以更浓的色彩倾向属和弦。
- 离调是用副属和弦（V7/X、VII7/X）为目标级建立临时属支持的进行；离调后须回归主调，不建立新调。
- 副属和弦必须按七和弦规则解决；临时变化音应上行（或按倾向）解决于同一声部，谨防对斜。
