# 模进

把一个由旋律与和声组成的短小片段（**动机**），在另一个高度上原样重复，称为**模进**。模进是功能和声时代最重要的展开手法之一：它以重复获得统一，以移位获得推进，广泛用于乐句的扩充与乐思的展开。

## 构成要素

一次模进由两个要素构成：

- **动机**：模进的原始片段，通常为一至两小节，包含明确的旋律轮廓与完整的和声进行（如一个 V7—I 或 II—V—I 的进行）；
- **移位音程**：动机每次重复所移动的音程距离。最常用的是**二度**（大二度或小二度），也用三度或四度；连续模进一般以二、三次为宜，次数过多会显得机械。

动机第一次出现称为**模进主题**，其后的每次移位重复称为**模进音组**（第一音组、第二音组……）。

## 守调模进

动机在**同一调性内**移位重复，各音组的音程结构随调式音级而微调（大二度可能变为小二度），称为**守调模进**。守调模进不离开调性，和声始终在主调的功能体系内运动，是最平滑、最常用的模进类型。

```abcjs
X: 1
T: 守调模进：动机按二度上行移位（C 大调）
M: 4/4
L: 1
K: C
[C,G,CE] [G,BDF] | [D,FAC] [A,Cea] | [E,Gce] [B,Dfa] ||
```

动机是"三和弦—上方二度的属七和弦"的进行，连续向上一级移动：每个音组内部的倾向关系都随调式音级自然调整，但旋律与和声的轮廓保持一致。

### 守调模进的和声内容

守调模进的和声可以是：

- **三和弦的固定模式**：如每个音组均为"三和弦—五度关系三和弦"（I—V、II—VI、III—VII）；
- **七和弦的固定模式**：如每个音组均为"自然音级七和弦—其下方五度三和弦"的解决模式；
- **转位的固定模式**：模式中可以包含六和弦、四六和弦或七和弦的转位，只要音组之间的移动保持同一公式。

```abcjs
X: 1
T: 含七和弦解决的守调模进
M: 4/4
L: 1
K: C
[G,BDF] [C,EGc] | [A,Cea] [D,FAd] | [B,Dfa] [E,Gce] ||
```

每个音组都是"自然音级七和弦解决于其下方五度的三和弦"（G7—I、Am7—II、B半减7—III）——模式固定，高度递升。

## 转调模进

每个音组各处于**不同的调**（或以副属和弦离调的方式倾向不同的目标），称为**转调模进**。音组的连接如同连续的小转调：前一个音组的目标调，正是后一个音组的出发调。转调模进离开调性中心较远，推动力更强，常用于乐曲的展开部分或转调的过渡地带。

```abcjs
X: 1
T: 转调模进：每个音组离调向下一级
M: 4/4
L: 1
K: C
[A,^CEG] [D,FAd] | [E,^GBd] [A,Cea] ||
```

第一音组中 A7（V7/II）解决到 II 级，随即 II 级的上方五度又被当作下一个目标；第二音组中 E7（V7/VI）解决到 VI 级——同一公式两次离调，调性重心逐级滑动。

## 模进的应用

模进最典型的用途是**扩充乐句**：在乐句本可终止的地方，以模进代替终止进行，把和声与旋律推向新的高度，再回到终止式收束。展开部、连接部中的模进更为自由——连续的转调模进可以在数小节内掠过多个调域，制造强烈的推进感。

```abcjs
X: 1
T: 以模进扩充乐句后再收束
M: 4/4
L: 1
K: C
[C,G,CE] [G,BDF] | [D,FAC] [A,Cea] | [G,BDF] [C,EGc] ||
```

第一、二小节以模进延展乐句，第三小节回到 D7—T 的终止进行收束——模进"拖延"了终止，也积蓄了回到主和弦的能量。

## 写模进的声部进行要点

1. **第一音组必须干净**：模进音组会复制主题的一切细节（包括错误），故主题本身不得含有平行五八度、对斜等瑕疵；
2. **音组之间同样要良好连接**：相邻音组交界处的声部进行按正常规则检查，音组内部模式中允许的某些紧缩进行（如七和弦的连续）在模进语境内是可接受的惯例，但仍以不刺耳为度；
3. **控制音域与次数**：连续二度上行模进会迅速攀升音域，注意各声部不越界；模进二至三次后应及时收束或转向；
4. **低音线条优先设计**：模进的整体效果很大程度取决于低音的走向（级进、跳进或音阶式），先写好低音再填上方声部。

## 小结

- 模进是动机在不同高度的原样重复，由动机与移位音程构成，以二度移位最常用，二至三次为宜。
- 守调模进在同一调性内按调式音级调整音程结构，是平滑的展开与扩充手段。
- 转调模进让每个音组各属不同调（常借副属和弦），推动力强，用于展开与转调过渡。
- 模进主题必须无瑕疵，音组间连接同样要良好；注意音域控制与低音线条的设计。
