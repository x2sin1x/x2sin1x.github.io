# 等和弦转调与持续音

本讲是古典和声板块的收束，处理两个此前多次埋下伏笔的专题：借助**等音变换**实现远关系转调，以及以低音持续音延展和声的空间感。

## 等音与等和弦

十二平均律中，音名不同而音高相同的音互为**等音**（如 G# 与 Ab）。由此，一个和弦可以用不同的音名拼写：同一个音响，可以解释为减七和弦、属七和弦或增五六和弦等不同结构——这样的和弦互称**等和弦**。

等和弦的价值在于：它让同一个音响在两个调性中拥有两种"身份"，从而成为跨越远关系的桥梁——听感上几乎没有跳变，调性却已换了世界。

## 减七和弦的等音转调

减七和弦是等音变换的最佳载体。它的四个音两两之间均为小三度（等音意义下），结构完全对称：把其中任何一个音当作"导音"，整个和弦就成为那个调的 DVII7。因此，**同一个减七和弦可以属于四个调**，并按四种方式解决。

C 大调的 DVII7（减七形态）为 B—D—F—Ab。减七和弦的四个音在等音意义下两两相距小三度、结构完全对称，因此其中任何一个音都可被当作"导音"：以 B 为导音，它解决到 C 大调；以 D 为导音（改写为 D—F—Ab—Cb），它便成为 Eb 大调的 DVII7，解决到 Eb 大调；同理还可重释为 F# 调与 A 调的导七——**同一个减七和弦属于四个调**，并有四种解决方式。

第一小节：该减七和弦作为 C 大调的导七（以 B 为导音）解决到 C 大调主和弦；第二小节：同一音响被重释为 Eb 大调的导七（以 D 为导音，音名改写为 D—F—Ab—Cb），落到 Eb 大三和弦——音响衔接几乎无缝，调性却移到了相距三个降号的远关系调。

### 等和弦转调的步骤

1. **到达减七和弦**：在原调中（常作为原调 DVII7 或 DDVII7）自然地引入一个减七和弦；
2. **等音重释**：把它改写为新调导七的拼写（记谱改变，音响不变）；
3. **按新调解决**：让它按新调导七的倾向解决到新调主和弦，并以新调终止式巩固。

### 增四六和弦与属七的等音关系

增四六和弦（德意志增六和弦）同样适于等音转调。C 大调的增四六和弦（Ab—C—Eb—F#）与 G# 上的属七和弦 G#7（G#—B#—D#—F#）音响完全相同，只是音名拼写不同：前者按增六度收缩解决到属音 G，后者则按属七规则解决到 C# 大调。因而这个和弦可以不改音响、只改身份，直接"跳"进 C# 大调一类的远关系调——德意志增六和弦到属七的等音转换，是浪漫主义作品中跨越远关系的常用暗道。

比较两类桥梁的分工：减七和弦等音只能通向与原调呈小三度、三全音关系的远关系调；增六和弦等音则通向半音上方的远关系调。二者合用，远关系转调的地图便基本完整了。

## 持续音

**持续音**（pedal，也称持续音踏板音）是低音部长时间保持（或以同音反复、八度跳动的方式延续）的一个音，其上方的和声却自由运动——低音与上方和声暂时"脱钩"，形成外声部之间的张力。

最常见的两种持续音以功能命名：

- **主音持续音（T 持续音）**：低音停在主音上，上方和声在 T 与 S 之间游离（如主和弦与下属和弦的交替）。主音持续音巩固调性中心，多用于乐曲的开始或结尾，音响宁静而辽阔；
- **属音持续音（D 持续音）**：低音停在属音上，上方和声（常含主和弦、下属和弦的转位）在属音上"摩擦"，紧张度持续堆积，多用于终止前的准备段或再现之前，期待属和声最终引爆为终止式。

前三小节低音始终是属音 g：上方先后出现主四六、D7、主和弦的音响——低音不动而和声翻涌，这是属音持续音的典型景观；最后一小节低音离开 g 进入主音，持续音结束，全曲收束于完全终止。

### 记谱与写作要点

1. **低音先行**：持续音是低音部的事件，写作时先固定低音，再在其上配置和声；
2. **记谱**：持续音占据低音声部，上方三声部按正常四部和声规则写作；持续音可用同音反复或八度跳动保持活力，也可整小节保持；
3. **音响协和的处理**：低音与上方和弦形成的二度、七度等不协和音程是持续音表现力的来源，但仍应避免生硬的对斜与不必要的不协和堆积；
4. **结束方式**：持续音以两种方式结束——低音**直接进入**终止式的属和弦或主和弦（如上例 g→c），或交由上方和声的终止进行收束；属音持续音几乎总以终止式结束，主音持续音则常在全曲结尾静静淡出。

### 功能意义

持续音把"低音＝功能基础"的常规暂时悬置：主音持续音让调性中心在一片和声云雾中始终清晰；属音持续音则像不断加压的弹簧，把终止式的到来推迟到听觉的最大期待。二者都以最经济的手段——一个不动的低音——获得最大的结构表现力。

主音持续音同样有独立的音响风景。下例中低音始终是主音 c，上方和声在主、下属之间交替：

低音 c 不动，上方声部在 C 大三和弦与 F 大三和弦的第二转位形态（C—F—A，即辅助性四六 S46）之间往返——下属功能被主音"垫"在下方，不稳定被抵消大半，只留下宁静的荡漆。这种写法常见于牧歌风结尾与合唱式的终止延长。

比较两种持续音的性格：主音持续音是"静止中的展开"——一切运动都汇入已然确立的中心；属音持续音是"期待中的堆积"——运动被悬在未解决的高度上，直到终止式把积攒的势能一并释放。

## 小结

- 等音使同一音响可作多种和弦解释；减七和弦结构对称，可属于四个调，是等和弦转调的主要桥梁。
- 等和弦转调三步骤：原调自然到达该和弦→等音重释为新调身份→按新调解决并巩固。
- 增四六和弦与属七和弦等音，可借以实现远关系转调。
- 持续音是低音保持而上方和声自由运动的手法：主音持续音巩固调性、多用于首尾，属音持续音堆积期待、多用于终止前。
- 持续音以低音直接进入终止和弦或由终止进行收束而结束，是古典和声中结构表现力的点睛之笔。
