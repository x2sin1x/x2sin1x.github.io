# 自然音体系转调

此前各讲中的离调只是调性内的"远足"。当音乐真正离开原调、在新调上稳定下来时，便是**转调**。本讲讨论只借助自然音体系和弦完成的转调——向**近关系调**的转调，这是古典作品中最常见、最基本的转调类型。

## 转调与共同和弦

转调的关键在于**共同和弦**（也称中介和弦）：一个既属于原调、又属于新调的和弦。它在原调中以某一功能出现，进入新调后被"重新解释"为新调的另一级——这个身份的转换，就是转调的枢纽。

自然音体系转调的全部材料都来自原调的调号内：不引入任何新的变化音（新调的导音等变化音在共同和弦**之后**才出现）。

## 近关系调

与新调关系最近的调，是那些调号相差不超过一个升降号、或共享大多数自然音的调：

- **平行调**：C 大调—a 小调，调号相同，共用全部自然音；
- **属方向调**：大调的属方向为上五度大调及其平行小调（C 大调→G 大调、e 小调）；小调的属方向为平行大调的属调，即上五度小调（a 小调→e 小调）；
- **下属方向调**：大调的下属方向为下五度大调及其平行小调（C 大调→F 大调、d 小调）；小调的下属方向为平行大调的下属调，即下五度小调（a 小调→d 小调）。

近关系调之间共享大量自然音级，因此总有足够多的共同三和弦可作中介——这正是自然音体系转调可行的原因。

## 转调的三个步骤

一个完整的转调过程可归纳为：

1. **确立原调**：用原调的终止式或明确的 D7—T 建立调性，使听众对原调深信不疑；
2. **共同和弦转义**：出现一个共同和弦，先按原调理解，随即在它后面接上新调的属功能和弦（含新调导音），使其被听成新调的某一级；
3. **新调确立**：以新调的终止式（D7—T，最好含新调的 K46）巩固调性，转调完成。

其中第 2 步是枢纽：共同和弦之后**必须紧跟新调的属功能和弦**，转义才得以实现；若接的仍是原调进行，它就只是原调的一个普通和弦。

### 转到平行小调

C 大调转 a 小调：两调共用全部自然音，a 小调的绝大多数和弦在 C 大调中都有。常用中介是 C 大调的 VI 级（即 a 小三和弦，在 a 小调中是主和弦 t）：VI 级之后接 a 小调的属七 E7（升 G），便完成了向平行小调的转义。反向（小调转平行大调）则更容易——直接把 t 当作大调的 VI 即可。

```abcjs
X: 1
T: C 大调转 a 小调
M: 4/4
L: 1
K: C
[C,EGc] [A,Cea] | [E,^G_Bd] [A,CEA] ||
```

第一小节末的 a 小三和弦在原调中是 VI 级；第二小节立即接 a 小调的属七 E7（含新导音升 G）并解决于 a 小调的主和弦——VI 级被听成新调的主和弦，转调完成。

### 转到属方向调

C 大调转 G 大调：共同和弦有 C 大调的 I（=G 调的 IV）、V（=G 调的 I）等。常用中介是原调的 V 级：G 大三和弦在原调是 D，进入新调听成 I，随后接 G 调的 D7（D—F#—A—C，含新导音 F#）确立新调。也可用原调 I 作为中介（= 新调 IV），经新调 K46—D7—T 收束。

```abcjs
X: 1
T: C 大调转 G 大调
M: 4/4
L: 1
K: C
[C,EGc] [G,BDg] | [D,^FAC] [G,BDG] ||
```

原调的 V 级（G）被重新听成新调的 I，接 G 调的 D7（升 IV 级 F# 即新导音）解决于 G 大三和弦——原调的属和弦"升格"为新调的主和弦。

### 转到下属方向调

C 大调转 F 大调：常用中介是原调的 I（= F 调的 V）或原调的 IV（= F 调的 I）。例如：C 大三和弦之后接 F 调的 D7（C7：C—E—G—Bb，含新七音 Bb），解决于 F 大三和弦——原调主和弦成为新调属和弦，新调的七音（Bb）宣告了转义。

```abcjs
X: 1
T: C 大调转 F 大调
M: 4/4
L: 1
K: C
[C,EGc] | [C,EGB_b] [F,CFA] ||
```

原调 I 在第二小节添加七音 Bb 变成 F 调的属七，随即解决于 F 大三和弦：原调主和弦"降格"为新调属，转调顺流而下。

## 转调与离调的区别

| | 离调 | 转调 |
| :--: | :--: | :--- |
| 新调是否确立 | 否，副属和弦解决后立即回归 | 是，以新调终止式巩固 |
| 结构位置 | 乐句内部，短暂闪现 | 乐段或更大结构的关键位置 |
| 语法 | 同（副属和弦解决于目标） | 同（共同和弦转义 + 新调终止） |

简言之：离调是"一句话里借了个词"，转调是"从此换了语言说话"。转调过程的第 2 步（共同和弦转义）与离调的机制相同，差别只在第 3 步——新调是否被终止式真正确立。

## 小结

- 转调是新调真正确立的过程；共同（中介）和弦的身份转义是其枢纽，其后必须紧跟新调的属功能和弦。
- 近关系调指平行调、属方向调与下属方向调，它们共享大量自然音，自然音体系转调即向这些调的转调。
- 转调三步骤：确立原调→共同和弦转义→新调终止确立。
- 典型路径：转平行小调以原调 VI 为中介接小调属七；转属方向调常以原调 V 为中介（= 新调 I）；转下属方向调常以原调 I 为中介（= 新调 V）。
- 离调与转调语法同源，区别在于新调是否被终止式确立。
