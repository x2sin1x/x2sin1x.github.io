# 和声大调与副三和弦

正三和弦确立了调性的骨架，但只用三个正三和弦写作，和声色彩难免单调。本讲引入两组扩充手段：**副三和弦**——利用调式内其余音级上的和弦丰富功能体系；**和声大调**——借用降 VI 级音，使下属功能获得新的暗色。

## 副三和弦

自然大调的 II、III、VI、VII 级三和弦称为**副三和弦**。它们的结构与功能归属如下：

| 级数 | C 大调结构 | 功能归属 | 说明 |
| :--: | :--------: | :------: | :--- |
| II | Dm（小三） | S | 下属功能，常以六和弦形式（II6）使用 |
| III | Em（小三） | 兼具 T 与 D 色彩 | 最中性的副三和弦，使用较少 |
| VI | Am（小三） | S（亦带 T 色彩） | 连接 T 与 S 的桥梁 |
| VII | Bdim（减三） | D | 导音上的减三和弦，是 D 的代表之一 |

副三和弦的意义在于**扩展各功能组的阵地**：S 组由 IV 扩展为 II—IV—VI，D 组由 V 扩展为 VII（及 V7），T 组可借助 III、VI 延续主和声。功能逻辑仍是 T—S—D—T，但组内有了更多选择，低音线条与和声色彩随之丰富。

```abcjs
X: 1
T: 副三和弦（C 自然大调）
M: 4/4
L: 1
K: C
[D,FAd] | [E,Gce] | [A,Cea] | [B,Dfa] ||
```

自左至右为 II、III、VI、VII 级三和弦：三个小三和弦与一个减三和弦。

### 常用进行

- **S 组内部的进行**：II 到 IV 是根音上三度的弱进行，力度较缓；更有力的是 VI—II—D 与 II—D：VI 作 S 的代表从 T 延伸出下属领域，II（常转位为 II6）再推向 D；
- **VI 替代 IV**：T—VI—II—D7—T 一类进行中，VI 使下属功能的进入更柔和；
- **III 连接 T 与 D**：T—III—D 的进行中，III 以其兼有的 T、D 色彩作中介，但 III—IV（D 色彩接 S）属反功能，应避免。

```abcjs
X: 1
T: T—VI—II6—D7—T
M: 4/4
L: 1
K: C
[C,EGc] | [A,Cea] | [F,ADa] | [G,BDF] | [C,EGc] ||
```

VI 引入下属色彩，II6（低音 F）继续巩固 S 功能并顺势进入 D7，功能运动环环相扣，低音 c—a—f—g—c 起伏自然。

## 和声大调

自然大调的 VI 级音降低半音，即得**和声大调**。C 和声大调的音阶为 C—D—E—F—G—Ab—B：降 VI 级音（Ab）与主音相距小六度，与导音相距增二度。

降 VI 级音主要进入**下属功能组**的和弦，使之蒙上一层暗色：

- 下属三和弦由大三变为小三，记作 **s**（小下属和弦）；
- II 级三和弦由小三变为减三，II7 由小七变为半减七，记作 **sII**（常以 sII6 出现）；
- 降 VI 级音上建立的三和弦 Ab—C—Eb 是小三和弦，记作 **tsVI**，功能上兼有主与下属的色彩。

和声大调的使用规律是：**降 VI 级音尽量保持在同一声部并作下行解决**（Ab→G），避免它与其他声部的还原 VI 级音紧接相撞。出现于下属和声中时，和声大调常带来柔和、忧郁甚至庄严的色彩，多用于结构收束处与抒情段落。

```abcjs
X: 1
T: 和声大调的下属组：s、sII6、tsVI（C 和声大调）
M: 4/4
L: 1
K: C
[F,_ACf] | [F,_A_Df] | [_A,C_Ea] ||
```

第一个和弦是 s（F 小三和弦，含降 VI 级音 Ab）；第二个是 sII6（减三和弦 D—F—Ab 的六和弦）；第三个是 tsVI（Ab—C—Eb）。三个和弦都因 Ab 而色彩转暗。

### 对斜禁忌

同一音级的自然形式与变化形式（如 A 与 Ab）若**紧接出现在不同声部**，形成一上一下的交错，称为**对斜**（虚假关系）。对斜使两个声部的线条突然"错位"，音响生硬，写作中应避免——让变化音与还原音出现在同一声部（平滑的半音进行），或让两者之间隔开足够的时间与声部距离。

## 阻碍进行与阻碍终止

属和弦之后不接主和弦、而接 **tsVI**（D—tsVI），称为**阻碍进行**。听感上，D 对主音的期待被低音上行的 tsVI "拦住"，和声在最后一步转了弯，故名阻碍。

将阻碍进行置于终止位置，即形成**阻碍终止**：它不能结束乐段，却能**推迟终止、扩充乐段**——阻碍之后，和声重新组织（常经 S 组）再次走向真正的终止。阻碍进行中低音作上行二度（G—Ab），D 的导音照常解决到 tsVI 的根音，七音（若有）照常下行，避免任何声部的不自然跳进。

```abcjs
X: 1
T: 阻碍进行 D—tsVI
M: 4/4
L: 1
K: C
[G,BDF] | [_A,C_Ea] | [F,_ACf] [G,BDF] | [C,EGc] ||
```

D7 之后接 tsVI，低音 g 上行到 Ab：期待的解决被延迟；随后经 s 再次进入 D7，以完全终止收束——这正是用阻碍进行扩充乐段的典型过程。

## 小结

- 副三和弦 II、III、VI、VII 扩展了三个功能组：II、VI 入 S，VII 入 D，III 兼具 T、D 色彩。
- 常用进行如 T—VI—II6—D7—T，功能逻辑不变而色彩更丰富；III—IV 一类反功能仍应避免。
- 和声大调降 VI 级，使下属组和弦（s、sII6、tsVI）色彩转暗；变化音应下行解决，谨防对斜。
- D—tsVI 为阻碍进行；置于终止处即阻碍终止，可推迟终止并扩充乐段。
