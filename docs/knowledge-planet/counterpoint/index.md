# 复调

两条或两条以上具有相对独立意义的旋律线同时结合，便构成**复调音乐**（Polyphony）。研究旋律线如何结合的写作方法称为**对位法**（Counterpoint）；这个词常用拉丁语 *punctus contra punctum*（音符对音符）解释。和声分析常从纵向音响入手，对位分析则还要追踪每条声部的横向走向：它们各自成线，又在节奏、音程和乐句上彼此配合。

复调与主调并不是互斥的两种风格。巴赫的赋格以模仿和独立声部组织材料，同时也有清晰的调性与和声进程；勃拉姆斯、弗兰克和肖斯塔科维奇等人的作品，也常在主调织体中融入对位写法。学习对位能帮助我们听清、组织和发展多条旋律线。

本模块分为两大板块：

- **[严格对位](/knowledge-planet/counterpoint/strict-counterpoint/)**：以富克斯《对位法》（*Gradus ad Parnassum*）中的五类对位练习为主线，循序练习一音对一音、二音对一音、四音对一音、切分对位与混合对位。这里的规则是特定教学体系中的写作约束，不等同于所有历史时期复调音乐的通则。
- **[复调写作](/knowledge-planet/counterpoint/polyphonic-writing/)**：从严格练习转向更灵活的写作，梳理对比复调、模仿、卡农与赋格，并介绍经文歌、创意曲、帕萨卡利亚等复调体裁。

## 前置知识

学习复调前建议先掌握基本乐理，可参考 [乐理](/knowledge-planet/music-theory/) 模块，尤其是 [音程](/knowledge-planet/music-theory/音程)、[调式](/knowledge-planet/music-theory/调式) 与 [调性](/knowledge-planet/music-theory/调性)；同时建议具备[古典和声](/knowledge-planet/harmony/classical-harmony/)基础，因为对位中协和与不协和音程的判定、留音的解决逻辑，都以和声学的音程理论为前提。
