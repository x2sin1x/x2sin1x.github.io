# 复调

两条或两条以上具有独立意义的旋律线按照一定的规则同时结合，便构成**复调音乐**（Polyphony）。研究这种多线条结合的学问称为**对位法**（Counterpoint），一词源于拉丁文 *punctus contra punctum*——"音符对音符"。如果说[和声](/knowledge-planet/harmony/)关注的是音的纵向叠置，那么复调关注的就是音的横向线条：每一条旋律都自成歌调，又与其他旋律彼此依存、互为烘托。

复调与主调并不是对立的两种风格。巴赫的赋格以复调线条为骨、以功能和声为脉；勃拉姆斯、弗兰克直至肖斯塔科维奇的作品中，复调技法始终是深化音乐思维的核心手段。可以说，对位法是旋律写作的最高语法。

本模块分为两大板块：

- **[严格对位](/knowledge-planet/counterpoint/strict-counterpoint/)**：以富克斯《对位法》（*Gradus ad Parnassum*）的五类对位体系为主线，在固定旋律上逐一练习一音对一音、二音对一音、四音对一音、切分对位与混合对位，掌握两条旋律结合的基本规则。
- **[复调写作](/knowledge-planet/counterpoint/polyphonic-writing/)**：从严格对位走向自由写作，梳理对比复调、模仿复调与卡农的技法，重点讲解赋格的结构——主题、答题、对题、间插段、紧接段，并介绍经文歌、创意曲、帕萨卡利亚等复调体裁。

## 前置知识

学习复调前建议先掌握基本乐理，可参考 [乐理](/knowledge-planet/music-theory/) 模块，尤其是 [音程](/knowledge-planet/music-theory/音程)、[调式](/knowledge-planet/music-theory/调式) 与 [调性](/knowledge-planet/music-theory/调性)；同时建议具备[古典和声](/knowledge-planet/harmony/classical-harmony/)基础，因为对位中协和与不协和音程的判定、留音的解决逻辑，都以和声学的音程理论为前提。
