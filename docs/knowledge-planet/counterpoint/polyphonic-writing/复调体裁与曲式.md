# 复调体裁与曲式

对位与模仿的技术，在音乐史中凝结为一系列体裁。沿着体裁的演变梳理，可以看到复调思维从 Vocal 到 instrumental、从严格到自由的完整轨迹；而复调作品的曲式逻辑——由声部进入与材料陈述驱动——也与主调音乐的乐段结构截然不同。

## 文艺复兴：声乐复调的黄金时代

- **经文歌**（Motet）：拉丁文宗教合唱，每个乐句以一个圣咏或自创旋律为"点"，各声部以[模仿](/knowledge-planet/counterpoint/polyphonic-writing/模仿复调)依次进入。帕莱斯特里那的经文歌是[严格对位](/knowledge-planet/counterpoint/strict-counterpoint/)的音响范本；
- **弥撒**：五乐章的宗教套曲，常用同一固定旋律（圣咏或世俗歌曲）贯穿各乐章，或以"模仿弥撒"的方式让每个乐章都从同一动机家族生长；
- **牧歌**（Madrigal）：世俗合唱，半音化和声与"绘词法"（词意驱动织体）预示了主调音乐的来临。

## 巴洛克：器乐复调的世纪

- **利切卡尔**（Ricercar）：赋格的直接前身，主题性格庄重、模仿连续；
- **幻想曲与坎佐纳**：材料更自由的多段落器乐复调；
- **创意曲**（Invention）：巴赫为教学而写。二部创意曲以单一动机的模仿展开为骨架；三部创意曲（sinfonia）则引入真正的对题与声部层次，是进入赋格写作前的最佳阶梯；
- **前奏曲与赋格**：即兴性前奏曲与严密赋格并置，是巴洛克器乐的核心套曲形态；
- **托卡塔**：炫技性的自由段落常嵌入赋格，形成"自由—严格"的对话；
- **众赞歌前奏曲**（Chorale prelude）：圣咏旋律（常在最高声部完整陈述）与其余声部的对位装饰结合，是[对比复调](/knowledge-planet/counterpoint/polyphonic-writing/对比复调)的宗教化形态；
- **帕萨卡利亚与恰空**（Passacaglia / Chaconne）：固定低音（或固定和声进行）之上的持续变奏，上层声部以对位、卡农层层叠加——巴赫 c 小调《帕萨卡利亚与赋格》BWV 582 是这一体裁的纪念碑。它展示了复调与变奏思维深刻的亲缘关系：**复调本身就是一种变奏——同一材料在不同声部、不同高度的重述**。

## 复调曲式的特点

复调作品的结构不由"乐句—乐段—再现"的主调逻辑构成，而由三个要素驱动：

1. **声部进入的次序**：谁先进入、间隔多远、在什么音区；
2. **材料陈述的位置**：主题每次出现于何调、由哪个声部承担；
3. **织体的密度曲线**：声部数的增减、模仿时距的松紧——赋格紧接段的渐紧，正是"密度曲线"塑造高潮的典范。

因此分析复调作品，先画"主题出现表"（何时、何调、何声部），再谈和声，最后才谈小节结构——次序与主调分析恰好相反。

## 后世的回声

浪漫主义时期，复调不再是主导体裁，却是深层语法：勃拉姆斯的室内乐以对位缜密著称，弗兰克《前奏曲、圣咏与赋格》直接复兴巴洛克套曲，雷格几乎以对位为毕生事业。二十世纪，欣德米特《调性游戏》（号称"二十世纪的平均律"）、肖斯塔科维奇 Op. 87、梅西安、勋伯格的十二音写作——尽管语言剧变，"多线条独立结合"的复调思维始终是严肃写作的基本功。
