# 复调写作

五类对位练习聚焦两条旋律如何结合；本板块继续讨论多条旋律如何组织。不同历史时期的复调写作有各自的调式、和声与声部规则：文艺复兴声乐复调不能简单套用后来的功能和声分析，巴洛克及后来的调性复调则常结合和弦功能来理解。无论风格如何变化，声部的可辨识性始终是重要的聆听线索。

按材料组织的方式，复调写作分为两大技术：

- **对比复调**：不同性格的旋律同时结合，以"差异"求统一；
- **模仿复调**：相同或相似的材料在声部间先后传递，以"呼应"建立统一。卡农通常持续遵循模仿规则；[赋格](/knowledge-planet/counterpoint/polyphonic-writing/赋格（一）：主题与呈示部)则在主题呈示后结合模仿、对比与调性展开。
