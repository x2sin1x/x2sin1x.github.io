# 复调写作

五类对位解决的是"两条线如何结合"；本板块要回答的是"多线条音乐如何构成"。自十八世纪以来，自由的复调写作都以功能和声为背景：对位声部之间的纵列音程被理解为[和弦](/knowledge-planet/music-theory/和弦)及其外音，不协和音的处理从严格模式中解放出来，跳进与节奏对比的空间大大放宽——但"每个声部都值得一听"的原则始终未变。

按材料组织的方式，复调写作分为两大技术：

- **对比复调**：不同性格的旋律同时结合，以"差异"求统一；
- **模仿复调**：同一材料在声部间先后传递，以"呼应"求统一。卡农把模仿贯彻到底，[赋格](/knowledge-planet/counterpoint/polyphonic-writing/赋格（一）：主题与呈示部)则把模仿、对比与和声逻辑熔于一炉，是复调艺术的最高形式。
