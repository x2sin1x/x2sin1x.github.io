# 赋格（二）：中间部与再现部

呈示部让各声部依次陈述主题之后，作品常通过调性变化、主题片段和不同声部组合继续展开。很多赋格会在后段回到主调或再次突出主题，但并不存在每首作品都遵循的固定“再现部”；分析时应以实际主题进入、调性布局和终止位置为依据。

## 间插段

把主题片段（常取其尾部动机或对题材料）作**模进**式的连锁推进、用以连接各次主题陈述的过渡段落，称为**间插段**（Episode）。间插段的职能有三：

- **喘息**：主题暂退，听觉得以回味；
- **转调**：模进的每一步搭一级台阶，把音乐送往新调——间插段是赋格转调的主要枢纽；
- **统一**：间插段全部取材于主题与对题，自由之中处处有根。

## 中间呈示与调性布局

中间部中，主题可能在新的调性上再次出现，这类主题陈述常称为**中间进入**（middle entries）。许多调性赋格会触及属调、关系大小调或下属方向等近关系调，但调性次序并非固定公式。每次进入的声部组合与音区也可能变化，形成不同的织体层次。

## 紧接段

**紧接段**（Stretto，旧译"密接和应"）是赋格最激动人心的手段：在主题尚未陈述完毕时，其他声部便开始模仿——主题追主题，时间距离被压缩到极限。写作紧接段要求主题经得起各种时距的"自我叠加"：主题的每个音都要能与自己的其他片段协和相处。因此老练的作曲家在**设计主题之初**就已规划好紧接的可能性。

紧接段通常安排在**再现部之前或再现部之中**：追逐密度步步收紧，音乐推向全曲高潮，然后主题最后一次从容亮相。并非每首赋格都有紧接段，但伟大的赋格几乎都有。

## 持续音

紧接段之前或高潮段落中，低音部（或高音部）常以**属持续音**（dominant pedal）驻留数小节，其余声部在其上交织冲突——不协和的堆积与悬而未决的张力，为回归主调蓄足势能。这与[四部和声](/knowledge-planet/harmony/classical-harmony/等和弦转调与持续音)中的持续音手法同源，但在复调织体中威力倍增。

## 再现部与结尾

后段若主题回到**主调**并完整陈述，可视为重要的回归点；它不一定构成严格意义上的再现部。常见处理包括：

- 声部全奏（最厚实的织体）；
- 主调紧接段或持续音上的最后冲刺；
- 结尾的终止式扩展，有时缀以托卡塔式的华彩走句或低音上的长持续音。

入门分析可以先寻找：**主题呈示 → 中间主题进入与间插段 → 后段的主题回归或高潮 → 终止**。这只是观察线索，不是固定模板；赋格的结构更依赖主题进入、调性布局和织体变化，而非套用奏鸣曲式分段。
