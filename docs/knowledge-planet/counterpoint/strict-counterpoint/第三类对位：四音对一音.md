# 第三类对位：四音对一音

第三类对位(Third Species)中,对位声部以四个四分音符对应固定旋律的一个全音符(4:1)。节奏密度进一步加大，弱位置增加到三个，**经过音与辅助音**成为线条流动的润滑剂——这一类练习的目标，是学会让密集的音符“总在走向某个协和音”。

## 不协和音的位置

四分音符的四个位置强弱分明：第一拍最强，第三拍次之，第二、四拍最弱。规则相应规定：

- 第一拍（强拍）必须协和；
- 第三拍也应协和；
- **第二拍与第四拍**（弱拍）可以用不协和音，但必须是**经过音**或**辅助音**，即由级进而来、向级进而去，两端被协和音夹住。

辅助音（neighbor tone）与经过音的唯一区别是运动方向：经过音沿原方向继续，辅助音则先离开再折返，围绕一个协和音作上、下方的环绕。

## 线条组织

- 每小节内部以级进为主，允许三度以内的少量跳进，但跳进后须级进返回；
- 相邻两小节之间，前一小节第四拍与本小节第一拍以级进相连最为流畅——"跑向"每个强拍，是第三类对位最重要的手感；
- 一小节内避免出现两个四度、五度跳进；
- 其余禁则（平行与隐伏五八度、强拍音程要求、结尾处理）与第二类对位相同。

## 例题分析

::: abcjs
X: 1
T: 第三类对位（固定旋律在下）
M: 4/4
L: 1/4
K: C
V: 1 clef=treble
c d e g | f e d c | B c e c | B c d B | c4 ||
V: 2 clef=bass
C4 | D4 | E4 | D4 | C4 ||
:::

逐小节观察不协和音的位置：第一小节第二拍的 d（对 C 构成九度）是 c–e 之间的经过音；第二小节第二拍的 e 与第四拍的 c 分别是经过音，第三拍的 d 恰为八度协和音；第三小节全部协和，作短暂的"喘息"；第四小节第二拍的 c 又是 b–d 之间的经过音。所有不协和音都落在弱拍、都以级进通过，强拍音程依次为八度、三度、五度、三度、八度，结尾以反向级进进入八度。

对位声部的轮廓值得注意：第一小节冲上高点 g，随后三小节逐级回落的"下坡"线条，与固定旋律先扬后抑的拱形互为镜像，两线条的独立性因此十分清晰。

## 练习建议

第三类对位最容易犯的毛病是"音堆砌"：四音一组若缺乏方向，就成了上下打转的音阶碎片。写作前先规划对位声部的整体轮廓（高点在哪里、何时冲、何时收），再填入四音组；每一组的末音就是下一组的目标，全曲由一连串"目标—抵达"构成。
