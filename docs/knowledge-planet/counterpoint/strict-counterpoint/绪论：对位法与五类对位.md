# 绪论：对位法与五类对位

当两条旋律同时发响时，每一纵列上的两个音之间都构成[音程](/knowledge-planet/music-theory/音程)。对位法的核心问题可以概括为一句话：**如何让两条各自成立的旋律，在每一个瞬间都组成可以被听觉接受的音程结合**。协和与不协和的判定、线条的起伏与呼吸、节奏的疏密与呼应，构成了对位写作的全部规则体系。

## 几种常见的旋律组织关系

按旋律材料的组织方式，可以先用以下几种常见关系来理解复调织体；实际作品中它们可能交织出现：

- **支声织体**（Heterophony）：同一旋律在多个声部中以不同装饰或节奏形态同时呈现，常见于多种传统音乐。它与下面的对比、模仿写作有所不同。
- **对比复调**：各声部用不同的旋律材料、节奏与轮廓同时结合，彼此形成性格上的对照。详见[对比复调](/knowledge-planet/counterpoint/polyphonic-writing/对比复调)。
- **模仿复调**：同一材料在不同声部先后出现，形成追逐与应答。详见[模仿复调](/knowledge-planet/counterpoint/polyphonic-writing/模仿复调)、[卡农](/knowledge-planet/counterpoint/polyphonic-writing/卡农)与[赋格](/knowledge-planet/counterpoint/polyphonic-writing/赋格（一）：主题与呈示部)。

严格对位训练能帮助学习者听辨两声部的纵向结合，但作品中的实际规则会随时期、风格、声部数量和写作目的而改变。

## 协和与不协和音程

两声部对位中，音程按协和程度分为三类：

| 类别 | 音程 | 处理 |
| :--: | :-- | :-- |
| 完全协和 | 纯一度、纯五度、纯八度 | 常用于乐句开头与结尾；中间可用，但需留意连续进行和声部独立性 |
| 不完全协和 | 大小三度、大小六度（及其复音程） | 音响饱满柔和，是对位进行的主体，可自由使用 |
| 不协和 | 大小二度、大小七度、一切增减音程，**以及两声部间的纯四度** | 在本专题的严格两声部练习中，须按相应类别的规则引入并解决；不能只凭“弱拍”判断是否合格 |

注意最后一条：在传统两声部对位教学中，纯四度通常按不协和处理；在多声部和声语境中，它可能因低音与其他声部的支持而具有不同功能。可参阅[四部和声](/knowledge-planet/harmony/classical-harmony/绪论与四部和声)。

## 固定旋律

本系列练习以固定旋律（Cantus Firmus）为骨架。为了便于初学写作，可以先按以下常见建议检查旋律；不同教材、调式与练习题会有差异：

- 由 8～13 个音构成，首尾都用调式主音；
- 以级进为主，跳进只使用三度、四度与五度，且跳进之后必须反向级进返回；
- 全曲只有一个高点音，通常位于中段偏后，高点之后旋律逐渐下行收束；
- 不重复相邻的音，同一方向的连续跳进至多两个，且总音程不超过八度；
- 结尾以级进进入主音。

::: abcjs
X: 1
T: 固定旋律（C 大调）
M: 4/4
L: 1/4
K: C
C4 | D4 | E4 | G4 | F4 | E4 | D4 | C4 ||
:::

这条八音旋律从主音 C 逐步上行至唯一高点 G，再级进回到主音，是便于练习的简化拱形轮廓。后面的谱例会沿用相同音高材料；部分例题为展示局部技法会截取或改写它，并在说明中标出变化。

## 五类对位总览

| 类别 | 对位声部时值 | 新增课题 |
| :--: | :-- | :-- |
| 第一类 | 全音符（1:1） | 协和音程的结合，平行与隐伏五八度的禁则 |
| 第二类 | 二分音符（2:1） | 弱拍经过性的不协和音 |
| 第三类 | 四分音符（4:1） | 弱拍辅助音，节奏密度的控制 |
| 第四类 | 切分二分音符（切分） | 强拍留音：准备—悬挂—解决 |
| 第五类 | 混合时值 | 全部规则的综合运用 |

::: abcjs
X: 1
T: 同一固定旋律上的第一类对位
M: 4/4
L: 1/4
K: C
V: 1 clef=treble
G4 | F4 | G4 | B4 | c4 | e4 | B4 | c4 ||
V: 2 clef=bass
C4 | D4 | E4 | G4 | F4 | E4 | D4 | C4 ||
:::

五类对位不是五种风格，而是一组由简入繁的练习：第一类聚焦协和音程结合，第二、三类练习节拍中的经过音与辅助音，第四类聚焦切分留音，第五类综合这些写法。具体规则仍需结合调式、声部位置和乐句终止来判断。
