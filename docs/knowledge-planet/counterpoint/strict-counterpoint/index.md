# 严格对位

1725 年，维也纳宫廷作曲家约翰·约瑟夫·富克斯出版了《对位法》（*Gradus ad Parnassum*，"攀上帕纳索斯山"）。全书以师生对话体写成：老一辈大师阿洛伊修斯（Aloysius，影射帕莱斯特里那）向学生约瑟夫斯（Josephus）传授以固定旋律为骨架的五类对位练习。这部著作确立了此后三百年对位教学的基本范式，巴赫、海顿、贝多芬、勃拉姆斯都曾在它的影响下研习对位。

严格对位的训练体系称为**五类对位**（Five Species）：以一条全音符写成的**固定旋律**（Cantus Firmus，缩写 CF）为基准，对位声部依次用同样的时值（第一类）、二分音符（第二类）、四分音符（第三类）、切分节奏（第四类）与混合时值（第五类）与之结合。由简到繁，每增加一类，就多掌握一种不协和音的处理方式。

记谱约定：例题采用两行谱，上声部为对位声部，下声部为固定旋律；以 `L: 1/4` 记谱，全音符为固定旋律的单位时值。
