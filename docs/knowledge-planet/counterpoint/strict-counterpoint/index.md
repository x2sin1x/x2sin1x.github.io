# 严格对位

1725 年，维也纳宫廷作曲家约翰·约瑟夫·富克斯出版了《对位法》（*Gradus ad Parnassum*，"攀上帕纳索斯山"）。全书以师生对话体写成：老一辈大师阿洛伊修斯（Aloysius，影射帕莱斯特里那）向学生约瑟夫斯（Josephus）传授以固定旋律为骨架的五类对位练习。这部著作确立了此后三百年对位教学的基本范式，巴赫、海顿、贝多芬、勃拉姆斯都曾在它的影响下研习对位。

严格对位常用**五类对位**（Five Species）逐步安排练习：以一条全音符写成的**固定旋律**（Cantus Firmus，缩写 CF）为基准，对位声部依次采用相同时值（第一类）、二分音符（第二类）、四分音符（第三类）、切分节奏（第四类）与混合时值（第五类）。这套练习把音程结合、经过与辅助音、留音等课题分步呈现；它是一种教学模型，不应直接当作所有复调风格的写作规范。

记谱约定：本组示例采用 C 大调音高材料以便辨认音程，谱例用两行谱表示，上声部为对位声部，下声部为固定旋律；`L: 1/4` 表示 ABC 记谱中的基本单位为四分音符，因此固定旋律每小节的 `C4` 等写法表示一个全音符。富克斯的原始教学语境以调式旋律为基础，本组 C 大调谱例是便于入门的移调与记谱简化。
