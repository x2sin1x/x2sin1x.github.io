# 曲式

音乐是时间的艺术：它不能像绘画那样被一眼望尽，只能随时间逐音展开。**曲式**（Musical Form）研究的正是音乐在时间中的组织方式——乐思如何陈述、发展、对比与回归，段落如何衔接与分界，调性如何布局与解决。如果把旋律与和声比作建筑的砖瓦，曲式就是建筑的蓝图与骨架；演奏者据此理解段落呼吸，分析者据此拆解作品，作曲者据此组织乐思。

本模块分为两大板块：

- **[小型曲式](/knowledge-planet/musical-form/small-forms/)**：从曲式的概念与结构功能入手，沿勋伯格《作曲基本原理》与卡普林《Classical Form》的体系梳理动机、乐句、乐段等基本结构，再依次学习一段曲式、二段曲式与三段曲式——一切大型曲式的细胞。
- **[大型曲式](/knowledge-planet/musical-form/large-forms/)**：在小型曲式的基础上，学习复三部曲式、回旋曲式、变奏曲式、奏鸣曲式与回旋奏鸣曲式，以及多乐章套曲与自由曲式——古典—浪漫时期绝大多数器乐作品的"建筑总图"。

## 前置知识

曲式分析以和声与复调为两翼：终止式划分段落，转调规划调性布局，赋格与卡农则直接生成某些曲式（如帕萨卡利亚、赋格套曲）。建议先学习 [乐理](/knowledge-planet/music-theory/) 与 [和声](/knowledge-planet/harmony/)，尤其是 [终止式](/knowledge-planet/harmony/classical-harmony/终止式) 与 [曲式中的和声布局](/knowledge-planet/harmony/pop-harmony/曲式中的和声布局)；[复调](/knowledge-planet/counterpoint/) 与 [配器](/knowledge-planet/orchestration/) 可结合作品分析穿插参考。
