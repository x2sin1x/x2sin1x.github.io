# 小型曲式

本板块以勋伯格《作曲基本原理》（*Fundamentals of Musical Composition*）与卡普林《Classical Form》的体系为主线，从最小的结构单位——动机——出发，经乐句与乐段，直到一段、二段、三段曲式。这三级台阶既是本课程的入门，也是一切大型曲式的构成细胞：复三部的每个部分往往是单三或单二，奏鸣曲式的主部副部常常就是一个个乐段。

学习中建议始终同时握着两把尺子：**材料**（哪些小节在重复、对比、再现什么）与**和声—终止**（每句停在什么和弦、什么调）。材料与调性两个坐标都标清了，曲式自然浮现。

记谱与标记约定：曲式部分用大写字母标记（A、B、A′，撇号表示变化再现），结构功能用小写标记（基本乐思 b、延续 c、终止式 cad）；调性用 T（主调）、D（属调）、S（下属调）、Rp（关系调）等缩写。
