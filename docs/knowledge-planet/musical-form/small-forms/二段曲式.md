# 二段曲式

**二段曲式**由两个功能不同的部分构成：A 段陈述并初步收束乐思，B 段展开、对比或回归新材料，并在整体上完成收束。它是巴洛克舞曲与古典歌曲的核心曲式，也是通往三段式与回旋曲式的桥梁——二段式的"再现尾巴"长到自成一句，就催生了三段式。

## 古二部曲式：巴洛克的标准图式

巴洛克组曲中的阿勒曼德、库朗特、吉格等舞曲几乎清一色采用**古二部曲式**（baroque binary），两端反复：

```text
||: A :||: B A′ :||
```

其精髓是**调性布局**（以大调为例）：

| 部分 | 内部走向 | 调性布局 |
| --- | --- | --- |
| A | 从 T 出发，以同一材料的模进推进 | T → D（属调收束） |
| B | 从 D（或关系调 Rp）出发，素材多取自 A | D → T（回归主调收束） |

小调作品则走 T → Rp（关系大调）/ D，B 段再经属方向回归。A、B 两段常以**同一主题材料**（同头）开始——对比不在旋律，而在**调性的旅程**：出发走向属，再走回家。巴赫《法国组曲》《英国组曲》的舞曲乐章是最佳分析对象。这种"属方向对比"是古典奏鸣曲式主—副部调性关系的直接祖先（见 [奏鸣曲式](/knowledge-planet/musical-form/large-forms/奏鸣曲式)）。

## 带再现的二段曲式

古典与浪漫时期，B 段尾部常**回归 A 段的材料**（多为其后半句，主调），形成：

```text
A (T 收束) — B (转属/转关系调、发展) — A′ 尾部再现 (T 收束)
```

再现尾巴使 A、B 之间的天平重新倾向统一，结构听感接近 A—B—A，但仍以两句为骨架。判断"二段还是三段"的通行标准：**再现是否构成结构上独立的部分**——若再现只有一小截、不足以自立为"部"，归二段；若再现是一个完整乐段，则是三段式。

## 平行与对比二段

- **平行二段**：B 段与 A 段同头开始（继承古二部传统），对比由调性与展开手法承担；
- **对比二段**：B 段引入全新主题与（可能的）新调性，对比更鲜明。

B 段的典型写法是**展开性过渡 + 再现**：先以 A 的动机模进、碎裂并转调，随后引出回归。这与卡普林所述"延续—终止"功能的放大完全同构。

## 起承转合

中国传统乐学以**起、承、转、合**概括的四句结构（4+4+4+4），与西方的对比二段关系密切：起、承完成 A（"承"常为"起"的合尾变化），转、合构成 B——"转"引入对比与新调倾向，"合"回归终止。民歌《茉莉花》、许多艺术歌曲主歌均属此类。它提示我们：句法关系（同头？合尾？对比？）是比曲式标签更本质的观察点。

## 分析示例

- 巴赫《法国组曲》第五首吉格：古二部曲式的调性布局范本；
- 舒伯特《野玫瑰》：带再现的二段曲式，B 段尾 A′ 完整而短小；
- 贝多芬《G 大调小步舞曲》主题段落：二段与三段之间的临界案例。

## 与三段式的界线

| | 二段曲式 | 三段曲式 |
| --- | --- | --- |
| 结构骨架 | 两句/两段，A—B（A′） | 三部分 A—B—A′ |
| 再现规模 | 局部（多为一小截或一句） | 完整部分 |
| 中部 | 无独立"中部"概念 | 有明确对比/展开的中部 |
