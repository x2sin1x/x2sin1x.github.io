# 奏鸣曲式

**奏鸣曲式**（sonata form，sonata-allegro form）是 18 世纪中后期在维也纳古典乐派手中定型的结构原则，也是西方器乐音乐史上效力最大的曲式。它处理一个根本的戏剧问题：**两个相互对比的调性与性格，如何在发展之后达成统一的回归？**

注意区分三个词：**奏鸣曲**（sonata）是多乐章套曲体裁（见 [套曲曲式与自由曲式](/knowledge-planet/musical-form/large-forms/套曲曲式与自由曲式)）；**奏鸣曲式**是单乐章的结构；**奏鸣曲式快板**是套曲第一乐章惯用的"快板 + 奏鸣曲式"组合。

## 总图式

```text
（引子）— 呈示部 —（反复）— 展开部 — 再现部 —（尾声）
```

| 部分 | 内容 | 功能 |
| --- | --- | --- |
| 引子（可选） | 慢速，常为属调或远关系调酝酿 | 铺垫与悬念 |
| 呈示部 | 主部—连接部—副部—结束部 | 陈述对比，副部转入新调 |
| 展开部 | 动机加工、模进、远关系调 | 制造冲突与漂泊 |
| 再现部 | 主部—连接部（改写）—副部（回归主调）—结束部 | 调性解决，戏剧闭合 |
| 尾声（可选） | 强调主调，可再展开 | 盖棺定论 |

## 呈示部：四位角色

呈示部内部按**结构功能**（见 [绪论](/knowledge-planet/musical-form/small-forms/绪论：曲式与结构功能)）划分为四区，古典分析习惯记作 P—TR—S—C：

- **主部 P**（primary theme）：主调、强节奏性格、常为 [乐句结构（sentence）](/knowledge-planet/musical-form/small-forms/动机、乐句与结构功能)，以半终止或完全终止收束；
- **连接部 TR**（transition）：取 P 的素材或全新材料，**唯一使命是把音乐送到新调**——常以碎裂、模进与属和声悬置结束，停在副调的属和弦上"开门"；
- **副部 S**（secondary theme）：**副调**（大调走属调，小调走关系大调或属小调）、抒情歌唱性格、多为[乐段](/knowledge-planet/musical-form/small-forms/一段曲式（乐段）)或其扩展，并以副调的完满终止收束；
- **结束部 C**（closing）：副调内反复终止式、巩固新调，性格常回归果断。

古典呈示部通常整体反复（现代演奏偶有省略）。莫扎特 K. 545 第一乐章是最透明的教例：P（C 大调）—TR—S（G 大调）—C，小节数不过七十，功能分毫不乱。

## 展开部：动机的远征

展开部对 P、S、TR 的材料进行加工：片段化（碎裂到一两小节）、模进链、倒影对位、力度与音区的极端化；调性走**远关系方向**（下属、平行小调、减七与拿波里氛围）。和声上它是一段"无家可归"的漂泊，通常以两大停顿节点收束：**假再现**（以错误调性闪现主题）与**属准备**（主调属和弦上的持续蓄势）。

## 再现部：闭合的艺术

再现部重走 P—TR—S—C 的次序，但有一处**必然的改动**：连接部改写路线不再转调，副部**以主调回归**——呈示部中"属调的副部"被"带回家里"，全曲的调性戏剧就此解决。这一改动是奏鸣曲式的灵魂：对比由调性对立（呈示）经瓦解（展开）走向同一化（再现）。浪漫派作家有时反其道而行（副部移向下属方向、三调呈示等），把"解决"改成"新出发"。

尾声绝非可有可无的"拖尾"：贝多芬把尾声写成"第二展开部"（《第三交响曲"英雄"》第一乐章），在主调上再做一轮发展，才宣告真正的终局。

## 调性布局总表

| 区段 | 大调作品 | 小调作品 |
| --- | --- | --- |
| P | T | t |
| S（呈示） | D | Rp（关系大调） |
| 展开部 | S、平行调、远关系漂泊 | 同左 |
| S（再现） | T | T（或同主音大调） |
| C / 尾声 | T | T / T 大调 |

## 分析示例

- 贝多芬《c 小调第八钢琴奏鸣曲"悲怆"》第一乐章： grave 引子 + 呈示部 + 展开部 + 再现部 + 尾声的全要素范本；
- 莫扎特《g 小调第 40 交响曲》第一乐章：小调奏鸣曲式的副部（降 B 大调）与再现回归；
- 贝多芬《第五交响曲》第一乐章：动机单一性与结构功能的极致示范。
