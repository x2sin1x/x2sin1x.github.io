# 回旋曲式

**回旋曲式**让一个主要主题（**叠部**，refrain，记作 A）反复出现，其间穿插新材料段落（**插部**，episode，记作 B、C、D…）：

```text
A — B — A — C — A …
```

它以"回家"的反复抚平插部带来的对比，天然具有明朗、舞蹈性、终乐章的气质——回旋曲是古典奏鸣曲（器乐奏鸣曲、协奏曲、交响曲）末乐章的常客。

## 五部回旋曲：ABACA

古典时期的标准形态。五个部分之外，常在 A 之后加连接，结尾加尾声：

| 部分 | 材料 | 调性 |
| --- | --- | --- |
| A | 叠部，完整乐段或单二 | T |
| B | 第一插部，新主题 | D（或 Rp） |
| A | 叠部再现 | T |
| C | 第二插部，对比更深或带展开性 | S / Rp |
| A | 叠部再现 + 尾声 | T |

要点有三：**叠部每次都在主调**（这是它与古二部曲式的根本区别——回旋的"家"从不搬走）；**插部一个比一个远**（调性对比逐级加深）；**插部性格多样**（歌唱性、舞曲性、展开始，甚至引入新速度）。贝多芬《献给爱丽丝》是五部回旋曲最透明的教学范例：A（a 小调）—B（C 大调）—A—C（F 大调）—A—尾声。

## 七部回旋曲：ABACABA

把插部增加到三个，并在尾部复现 B：

```text
A B A C A B A
```

第二插部 C 是全曲的"深渊"——最远调性、最强烈对比，此后音乐开始收拢：B 的回归宣告返程，末次 A 与大型尾声完成闭环。莫扎特、贝多芬的终乐章大量采用此式；当 C 部分本身承担奏鸣曲式展开部的功能时，整个结构就滑向 [回旋奏鸣曲式](/knowledge-planet/musical-form/large-forms/回旋奏鸣曲式)。

## 历史变体

- **巴洛克回旋曲**（法国 rondeau 传统）：叠部短小（常仅乐句级），在主调反复出现，插部之间的"回家"更像副歌——库泊兰、拉莫的大键琴曲、巴赫《降 E 大调奏鸣曲》末乐章是典型。叠部多为乐段级的，是古典 ABACA 的前身；
- **浪漫派小回旋曲**：叠部与插部规模缩小、速度轻快（常标 Allegretto）、插部个性鲜明——门德尔松《无词歌》、舒伯特即兴曲中的回旋乐章；
- **特性化的回旋**：浪漫派常把回旋骨架藏进性格小品与舞曲（如圆舞曲中的 A B A C A D A），圣—桑《天鹅》所在的《动物狂欢节》、拉威尔的《波莱罗》（固定旋律/固定节奏的"单主题回旋思维"变体）都演示了回旋原则的弹性。

## 叠部再现的变化

再现并非复印：可改配器（从钢琴到乐队）、可加花、可缩为半截。但**主调与可辨认性**必须保住——叠部一旦改调或面目全非，回旋感即告瓦解。

## 分析示例

- 贝多芬《第八钢琴奏鸣曲"悲怆"》第三乐章：五部回旋曲（rondo proper）；
- 莫扎特《A 大调钢琴奏鸣曲》K. 331 第三乐章（Alla Turca）：带插部性中段与尾声的回旋结构；
- 肖邦《小狗圆舞曲》：回旋原则与圆舞曲体裁的融合。
