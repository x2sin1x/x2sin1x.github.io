# 套曲曲式与自由曲式

一部奏鸣曲、一部交响曲由多个各自完整的乐章组成——乐章之间的组合关系是**套曲曲式**（cyclic form）的课题；而浪漫派以降，大量作品既非标准曲式也非传统套曲，则归入**自由曲式与混合曲式**。本讲收束全课程：从最大尺度看曲式的组织原理。

## 多乐章套曲：古典的平衡术

古典—浪漫时期器乐套曲的标准布局（以四乐章交响曲为代表）：

| 乐章 | 速度与性格 | 常用曲式 |
| --- | --- | --- |
| 第一乐章 | 快板，戏剧性 | 奏鸣曲式（可带慢引子） |
| 第二乐章 | 慢板，歌唱性 | 复三、变奏曲式，偶见奏鸣曲式（无展开的"奏鸣曲行板"） |
| 第三乐章 | 小步舞曲/谐谑曲 | 复三部曲式（小型作品可省） |
| 第四乐章 | 快板或急板，终曲 | 回旋曲式、回旋奏鸣曲式、奏鸣曲式、变奏曲式 |

三种体裁的变体：

- **奏鸣曲/弦乐四重奏**：三乐章（快—慢—快，省第三乐章）或四乐章；
- **协奏曲**：三乐章（快—慢—快），第一乐章采用带**双呈示部**的协奏曲式（乐队先呈示、独奏再呈示），并嵌入**华彩段**（cadenza）；
- **交响曲**：四乐章全编制；贝多芬把第三乐章由小步舞曲改造为谐谑曲，并在《第九交响曲》中引入人声——套曲框架本身就是可被突破的"最大曲式"。

### 套曲的统一手段

乐章若各自为政，套曲便只是曲集。古典作曲家用三重手段实现整体性：

1. **调性框架**：首尾乐章同主调（同或异调式），中间乐章走下属/关系方向；
2. **乐章间连接**：谐谑曲不停顿地滑入终曲（贝五第三→第四乐章的著名过渡）；
3. **动机与循环主题**：同一动机贯穿各乐章（贝五的"命运节奏"），或固定主题在各乐章轮回（cyclic theme，弗朗克《d 小调交响曲》、圣—桑《第三交响曲"管风琴"》）。

浪漫派进一步追求"整体艺术"：柏辽兹《幻想交响曲》的**固定乐思**（idée fixe）五个乐章变形轮回；瓦格纳的乐剧以主导动机织成巨型"歌剧套曲"。

## 组曲：另一种套曲

- **巴洛克舞曲组曲**：阿勒曼德—库朗特—萨拉班德—吉格为核心的舞曲序列，同调性、异性格，前可加前奏曲，中可插双舞曲（double）；
- **浪漫组曲**：从戏剧/舞剧配乐编选（比才《卡门组曲》、格里格《培尔·金特》第一、二组曲），复三与回旋的中小型曲式占主导；
- **现代组曲**：电影、舞剧音乐的原生套曲化。

## 自由曲式与混合曲式

浪漫晚期以来，作曲家开始拆散标准图式：

- **多部自由结构**：李斯特 b 小调奏鸣曲以一个三十余分钟的单乐章，把奏鸣曲式的呈示—展开—再现折叠进"慢—快—慢—赋格—再现"的自由段落，双主题变形贯穿；
- **体裁命名曲**：幻想曲、狂想曲、随想曲、叙事曲——名称即宣言"结构跟着乐思走"；其内部仍常可辨认出三段、回旋、变奏的局部骨架（**混合曲式**：如"回旋—奏鸣—变奏"复合）；
- **单乐章套曲化**：理查·施特劳斯的交响诗、西贝柳斯的交响诗以"乐段级转调 + 主题变形"完成叙事；
- **中国实践**：小提琴协奏曲《梁山伯与祝英台》以单乐章奏鸣曲式承载戏曲叙事（呈示部对应"相爱"、展开部"抗婚"、再现部"化蝶"），是"外来曲式 + 本土音乐语言"的经典示范。

## 曲式分析的总纲

至此可以总结全课程的方法论：

1. **先找终止与调性**，划出大轮廓；
2. **再标材料关系**（重复、对比、再现、变奏），确定各级字母；
3. **核对功能**：每一块在"陈述/延续/终止"中扮演什么角色；
4. **看比例与层级**：部分内部是什么曲式？比例是否失衡？
5. **最后下标签**——标签是分析的终点，不是起点。

曲式规则不是牢笼，而是历代作曲家与听众之间的"合同"：遵守它，对比与回归才能被听见；违反它，那违反本身才有意义。理解规则，正是为了听懂每一次打破。
