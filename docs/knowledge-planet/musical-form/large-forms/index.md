# 大型曲式

本板块在[小型曲式](/knowledge-planet/musical-form/small-forms/)的基础上学习大结构：复三部曲式以"部分套部分"的方式把单三放大，回旋曲式以叠部—插部的循环平衡对比与统一，变奏曲式在重复中求变化，而奏鸣曲式则把对比、发展与调性回归凝练成古典器乐最高效力的结构原则。最后以套曲曲式收束——交响曲、奏鸣曲、协奏曲的多乐章布局，以及浪漫派以降的自由曲式。

大型曲式的分析要点有二：一是**层级**（每个部分内部又是什么曲式？），二是**调性布局**（每个部分、每个主题各在什么调，何时回归？）。建议养成边听边画"结构图"的习惯：横向标小节与字母，纵向标调性与终止，一部作品的全景随即展开。
