# 回旋奏鸣曲式

**回旋奏鸣曲式**（sonata-rondo）是 [回旋曲式](/knowledge-planet/musical-form/large-forms/回旋曲式) 与 [奏鸣曲式](/knowledge-planet/musical-form/large-forms/奏鸣曲式) 的杂交：外观是回旋（叠部反复出现），骨架是奏鸣（两大主题先对比后统一）。它是古典器乐套曲**终乐章**最盛行的曲式。

## 总图式

```text
A — B — A′ — C（展开部）— A — B′ — A″（— 尾声）
```

| 回旋位置 | 奏鸣对应 | 调性 |
| --- | --- | --- |
| A（叠部=主部 P） | 主部 | T |
| B（第一插部=副部 S） | 副部 | D / Rp |
| A′ | 主部回归 | T |
| C（第二插部） | 展开部 | 远关系，展开性 |
| A | 主部再现 | T |
| B′ | **副部回归主调** | T |
| A″ | 终局叠部 | T |

关键在两处"奏鸣基因"：其一，**B 在呈示时走属/关系调**（如同奏鸣曲式副部），在再现时**回归主调**——调性解决的戏剧原封不动；其二，中部 C 采用展开部手法（模进、碎裂、远调漂泊），而非古典回旋曲中稳定的第二插部。

## 与相邻曲式的界线

| | 五部回旋 ABACA | 回旋奏鸣曲 | 奏鸣曲式 |
| --- | --- | --- | --- |
| 中部 | 稳定插部（新主题） | 展开性中部 C | 展开部 |
| B/S 再现 | 无此问题（插部不回归） | B 再现且**转回主调** | S 再现转回主调 |
| 主题再现次数 | A 反复三次 | A 反复四次 | P 再现一次 |

判定口诀：**看 B 是否"先出外乡、后回家"**——B 两次出现且第二次在主调，就是回旋奏鸣曲式；C 是否展开性则是辅助判据。界线上常有中间形态：莫扎特的一些终乐章中 C 只是轻快的第二个插部，结构便介于 ABACABA 与回旋奏鸣曲之间。

## 两种布局

- **七部式**（完整回旋奏鸣曲）：A B A′ C A B′ A″，如上表，最常见；
- **五部式**（简化）：A B A′ B′ A″，省去展开部或将其压缩为连接——小型作品与莫扎特协奏曲终乐章常见。

附属部分照奏鸣曲式惯例：慢速引子（偶见）、连接与尾声（终乐章尾声常常盛大，做整套作品的冲刺）。

## 为何适合终乐章

终乐章要求**明朗、可反复聆听、有余韵**：叠部的反复赋予"返场"般的亲切，副部与展开部提供足够的规模感，而尾声承接全曲的势能。贝多芬《悲怆》奏鸣曲第三乐章（c 小调）是标准教例：A B A′ C A B′ A″ + 尾声，B 呈示于降 E 大调、再现于 c 小调。

## 分析示例

- 贝多芬《c 小调第八钢琴奏鸣曲"悲怆"》第三乐章：回旋奏鸣曲式的教科书；
- 莫扎特《G 大调弦乐小夜曲》K. 525 第一乐章：奏鸣曲式外壳下的回旋气质（对照听辨）；
- 贝多芬《第一交响曲》第四乐章：以玩笑式引子开路的回旋奏鸣终章。
