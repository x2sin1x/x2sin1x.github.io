# 马克思主义

![](/knowledge-planet/marxism/assets/imgs/cover.png)

马克思主义是由马克思、恩格斯创立的，关于自然、社会和人类思维发展一般规律的科学，是关于无产阶级和全人类解放的学说体系。它由马克思主义哲学、马克思主义政治经济学和科学社会主义三个部分组成，是一个逻辑严密、内在统一的完整理论体系。

## 发展史

马克思主义产生于 19 世纪 40 年代的欧洲：工业革命推动资本主义迅速发展，无产阶级作为独立的政治力量登上历史舞台，为其诞生提供了社会经济条件和阶级基础；德国古典哲学、英国古典政治经济学和英法空想社会主义则为其提供了直接的理论来源。马克思、恩格斯批判地继承这些思想成果并实现革命性变革，于 1848 年发表《共产党宣言》，标志着马克思主义的公开问世。此后，马克思主义在指导无产阶级革命的实践中不断丰富和发展，经列宁主义过渡到马克思主义中国化的理论成果（参见[列宁主义](/knowledge-planet/leninism/)与[毛泽东思想](/knowledge-planet/maoism/)板块）。

## 三大组成部分

### 马克思主义哲学

马克思主义哲学即辩证唯物主义和历史唯物主义，是马克思主义理论体系的科学世界观和方法论基础。它坚持物质第一性，以对立统一规律为核心的唯物辩证法揭示事物发展的普遍规律，并以实践为基础阐明了认识的本质与发展过程；历史唯物主义则揭示了生产力与生产关系、经济基础与上层建筑的矛盾运动，第一次科学地说明了人类社会发展的基本规律。

### 马克思主义政治经济学

马克思主义政治经济学以劳动价值论为起点、以剩余价值学说为核心，剖析了资本主义生产方式的运行规律及其内在矛盾：货币转化为资本、剩余价值的生产与分配、资本积累的历史趋势，以及周期性经济危机的根源。它科学论证了资本主义制度的历史暂时性，是“马克思理论最深刻、最全面、最详细的证明和运用”。

### 科学社会主义

科学社会主义是马克思主义理论体系的核心与理论归宿。它以唯物史观和剩余价值学说为两大理论基石，阐明了资本主义必然灭亡、社会主义必然胜利的客观规律，指明无产阶级是变革资本主义社会的伟大力量，论证了无产阶级专政是由资本主义走向共产主义的历史过渡，并描绘了共产主义与人的解放这一最终目标。

## 三大组成部分的内在联系

马克思主义的三个组成部分不是彼此孤立的：马克思主义哲学是理论基础，提供科学的世界观与方法论；马克思主义政治经济学以这一世界观研究资本主义社会，是理论展开的主要论证；科学社会主义则在前两者的基础上得出实践结论，是全部理论的核心与归宿。三者相互贯通、有机统一，共同构成关于无产阶级和人类解放的完整学说，恩格斯在《反杜林论》中第一次对这一体系作了系统阐述。
