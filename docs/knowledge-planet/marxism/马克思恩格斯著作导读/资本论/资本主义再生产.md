# 资本主义再生产

> 本篇对应《资本论》第一卷第七篇前半（第二十一至二十二章）。

任何生产都不能一次了结，必须不断重复。把生产过程当作连续不断的过程看，就是**再生产过程**。

## 简单再生产：抽出积累来观察

先假定资本家把全部剩余价值用于个人消费，生产在原有规模上重复——这是**简单再生产**。它虽是抽象，却能把资本主义关系再生产出来的机制暴露无遗。

连续观察几个生产周期，三个假象被打破：

1. **可变资本是资本家预付的？**否。第一个周期后，工人领到的工资是上期自己生产的产品卖出的货币。**工人自己养活了自己，还养活了资本家。**
2. **全部资本都是资本家"劳动"积累的？**否。只要生产连续进行，任何资本经过若干周期都会被剩余价值替换殆尽。例如资本 1000 镑，每年带来剩余价值 200 镑全部被消费，则 5 年后 1000 镑原值已被消费完，账面资本 1000 镑全是**积累起来的剩余价值**。
3. **工人个人的消费是"自己的事"？**否。工人的消费只是劳动力的再生产，正如给机器上油是生产的必要环节。工人阶级即使领取工资，也只是在为资本**再生产出劳动力**。

**结论**：再生产不仅是物质资料的再生产，而且是**资本主义生产关系的再生产**——一边再生产出资本，一边再生产出雇佣工人。马克思对此的概括："资本主义生产过程……既生产商品，也生产和再生产资本关系本身：一方面是资本家，另一方面是雇佣工人。"

## 扩大再生产与积累的现实形态

现实中的资本家不把剩余价值消费光，而是把其中一部分**转化为新的资本**，使生产在扩大的规模上进行——这就是**资本积累**。

$$
\text{剩余价值 } s \;\longrightarrow\; \underbrace{a_{\text{消费}}}_{\text{资本家消费}} + \underbrace{a_{\text{积累}}}_{\text{追加的 } c' + v'}
$$

**例子**：资本 10000 镑带来剩余价值 2000 镑。资本家消费 1000 镑，把另 1000 镑追加为资本（设 $c' = 800, v' = 200$），第二年资本为 11000 镑，剥削规模扩大。

### 积累的动机

- 资本的本性：价值增殖是无止境的，"作为资本的货币没有终点"；
- 竞争的强制：不积累就落后，落后就被淘汰——"竞争使资本主义生产方式的内在规律作为外在的强制规律支配着每一个资本家"。

### 商品生产所有权规律转变为资本主义占有规律

最初，商品交换以双方各自拥有商品为前提，是所有权规律。但在再生产中：

- 劳动力的不断买卖在形式上始终是等价交换；
- 但购买劳动力的货币本身是**无偿占有的他人劳动（剩余价值）**，购买的结果又产生新的剩余价值。

于是：**商品生产的所有权规律，转变为资本主义占有规律**——以等价交换为形式，以无偿占有他人劳动为内容。"所有权对于资本家来说，表现为占有别人无酬劳动或产品的权利，而对于工人来说，则表现为不能占有自己产品的权利。"

> 这一规律性转折表明：剥削不是对交换规律的违反，恰恰是**在等价交换的基础上**、随劳动力成为商品而必然发生的。这是马克思主义政治经济学区别于一切"分配正义"批判的关键。
