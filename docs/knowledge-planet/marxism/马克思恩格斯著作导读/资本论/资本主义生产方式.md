# 资本主义生产方式

> 本篇对应《资本论》第一卷第四篇《相对剩余价值的生产》（第十二至十五章）。

资本主义生产方式的本质规定是：**生产资料归资本家所有，工人以出卖劳动力为生，生产的直接目的是榨取剩余价值。**在这一本质规定下，生产的技术组织经历了三个历史阶段，每个阶段都对应着相对剩余价值生产的一个步骤。

## 从形式隶属到实际隶属

- **形式隶属**：工人还保留着独立生产者的外表（如早期家庭织工），只是在交换关系上依附于资本；
- **实际隶属**：随着协作、分工与机器体系的建立，工人完全被吸纳进资本的生产机体，成为资本的"有意识的器官"。

相对剩余价值生产的三个阶段，就是实际隶属不断加深的过程。

## 第一阶段：简单协作

许多工人在同一资本指挥下、在同一过程中协同劳动，尚无明确分工。

- 协作创造了一种**新的社会劳动生产力**：一百个人同时搬运的重量远超一百个人单独搬运之和；
- 这种社会生产力被资本无偿占有——"和同样数量的单个的个人工作日的总和比较起来，结合工作日可以生产更多的使用价值"；
- 管理职能（指挥、监督）作为协作过程的必然产物，在这里表现为**资本的职能**，为后面"监督劳动"的二重性埋下伏笔。

## 第二阶段：工场手工业

以**分工**为基础的协作。工人被固定在一种局部操作上（如制针被分为 18 种操作）。

- 工人成为**局部工人**，终身从事一种片面职能，发展为"畸形物"；
- 劳动工具随操作专门化、多样化，为机器体系准备了物质条件；
- 劳动生产率提高的代价是**工人的片面化**："工场手工业把工人变成局部机器的附件。"

## 第三阶段：机器大工业

劳动资料从工具变为**机器体系**——发动机、传动机构、工具机三结合。马克思的分析要点：

1. **机器本身与机器的资本主义使用要区分**："机器本身对于把工人从生活资料中'游离'出来是没有责任的。"矛盾出在机器的资本主义应用方式上。
2. **机器与工人**：机器排挤工人（织布工人反对织布机），降低劳动强度门槛，使妇女儿童被卷入工厂；工人从使用工具的人沦为"机器的侍从"。
3. **劳动对资本的实际隶属完成**：工人离开机器体系就无法生产，只能依附于资本。
4. **工厂法的教育条款与新技术**：马克思敏锐地指出，大工业的原则是"全面的流动性"，要求"全面发展的个人"取代局部工人——教育与生产劳动相结合是大工业自身提出的要求。

## 概括：相对剩余价值的历史逻辑

$$
\text{协作} \;\longrightarrow\; \text{工场手工业（分工）} \;\longrightarrow\; \text{机器大工业}
$$

每一步都提高社会劳动生产率 → 降低生活资料价值 → 缩短必要劳动时间 → 提高相对剩余价值率。资本对剩余价值的追逐，就是这样**无意识地**重塑了整个社会的技术形态与阶级结构。
