# 各种收入及其源泉

> 本篇对应《资本论》第三卷第七篇《各种收入及其源泉》（第四十八至五十二章），是全三卷的终章，也是商品拜物教批判的最终完成。

## 三位一体公式

马克思把资产阶级经济学的表面世界概括为**"三位一体的公式"**：

$$
\text{资本} - \text{利息}，\quad \text{土地} - \text{地租}，\quad \text{劳动} - \text{工资}
$$

即：资本天然带来利息（利润），土地天然带来地租，劳动天然带来工资——三种收入仿佛来自三个互不相干的源泉，社会分配因此显得"天经地义"。

马克思逐项揭示其虚妄：

1. **资本不是物**，而是社会关系（见[货币转化为资本](/knowledge-planet/marxism/马克思恩格斯著作导读/资本论/货币转化为资本)）；
2. **土地没有价值**，天然体不可能"创造"价值——地租来自农业剩余价值的让渡（见[资本主义地租](/knowledge-planet/marxism/马克思恩格斯著作导读/资本论/资本主义地租)）；
3. **劳动本身没有价值**，工资是劳动力价值的表现（见[工资](/knowledge-planet/marxism/马克思恩格斯著作导读/资本论/工资)）。

公式把三个不能并列的东西（生产要素的自然形态与所对应的社会关系）强行并置，是"庸俗经济学"的理论标本。它抹去的正是中间那个真正的事实：**利息、地租、工资全部是剩余劳动或必要劳动的转化形式**。

## 分配关系与生产关系

有人主张：生产技术不断进步，但"分配"可以独立改革——只需调整工资、利润、地租的比例。马克思反驳：**分配关系不过是生产关系的表现**。

- 工资以雇佣劳动为前提，利润以资本为前提，地租以土地所有权垄断为前提；
- 这些前提本身就是一定的**生产关系**；
- 因此一定的分配关系与一定的生产关系"具有历史的、暂时的性质"——随着生产力与生产形式的矛盾发展，它们必然被更高级的社会形态取代。

资本主义生产方式的两个特征（产品作为商品、剩余价值生产为直接目的）决定了其分配结构；分配关系的变革不能脱离生产关系的变革。

## 阶级（未完成的终章）

第三卷以《阶级》一章开头收尾——而这一章只写了一页多便中断了。马克思开宗明义：资本家、土地所有者、雇佣工人这三大阶级构成现代社会的骨架；随后他提出"什么事情形成阶级？……什么事情使雇佣工人、资本家、土地所有者成为社会三大阶级？"——手稿到此为止。

恩格斯在此加注："手稿到这里就中断了。"这个未完成的结尾成了永远的悬念，也把"阶级分析"的完整论述留给了后来的马克思主义者。

## 全书终点：拜物教的完成与批判

回顾三卷的逻辑：

$$
\underbrace{W = c + v + s}_{\text{第一卷：价值的本质}} \;\longrightarrow\; \underbrace{W' - G'}_{\text{第二卷：价值的实现}} \;\longrightarrow\; \underbrace{k + \bar{p}' = \text{利息} + \text{企业主收入} + \text{地租}}_{\text{第三卷：价值的分配形态}}
$$

越接近现象表面，剩余价值的痕迹越淡：从剩余价值 → 利润 → 平均利润 → 利息与地租，剥削的实体被一层层现象包裹，直到三位一体公式把它完全"蒸发"。马克思的全部理论工作，就是**从现象倒推回本质**，再从本质**解释**现象。

> **总结**：《资本论》最终证明——现代社会的全部"收入"都渊源于工人阶级的活劳动；资本主义的各种分配形式只是这一事实的日益颠倒的表现。理解了这一点，也就理解了为什么马克思说他的学说是"无产阶级的政治经济学"。
