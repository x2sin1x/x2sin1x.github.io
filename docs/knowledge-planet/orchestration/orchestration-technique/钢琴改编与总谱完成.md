# 钢琴改编与总谱完成

配器的最后一公里是案头工作：把钢琴草稿（或他人的钢琴作品）管弦化，并把总谱写到演奏者拿到分谱就能排练的程度。这既是技术收尾，也是对前面所有知识的总检验。

## 从钢琴织体到乐队织体

钢琴谱常把旋律、和声、低音压进两只手的十根手指里。改编的第一步是**拆解功能层**（见[管弦乐织体与低音声部](/knowledge-planet/orchestration/orchestration-technique/管弦乐织体与低音声部)）：

1. 辨认旋律、对旋律、和声填充、低音各占哪些音；
2. 为每层选定实现手段——旋律给哪件乐器、音型交给谁、低音以什么编制铺底；
3. 把钢琴式的"音块"改写为各乐器可独立呼吸的线条。

钢琴织体的常见陷阱与对策：

- **八度与和弦的堆积**：钢琴靠八度加厚音量，乐队中应改用音色叠加与和声填充，而非让每件乐器都奏八度；
- **跨手音型**：分解和弦跨几个八度，可拆给竖琴、弦乐拨弦与木管接力，但保持音型的连贯感；
- **踏板共鸣**：钢琴延音踏板制造的混响，在乐队中由持续音声部（圆号、中提琴分部、竖琴）还原；
- **极端音区**：钢琴两端音区在乐队中未必有对应音色，必要时改写 octave 或调整音高布局。

## 改编的操作顺序

1. **宏观设计**：先划分全曲的音响布局——哪里弦乐为主、哪里全奏、哪里精简到独奏，画出"音响地图"；
2. **逐段配器**：按功能层分配乐器，同一段落内避免不必要的音色更换；
3. **平衡预演**：在脑内（或打谱软件回放中）检查各层力度是否拉开层级；
4. **回头修订**：整曲完成后通读，检查音色节奏——各段落"换色"的时机是否与音乐结构同步。

## 完成总谱

交给抄谱与排练之前，总谱须达到以下规范：

- **谱面排列**：按木管—铜管—打击乐—竖琴/键盘—弦乐的标准顺序，各组用纵线分隔；移调乐器按惯例记谱并标注调号（圆号传统上不写调号，临时变音记谱）；
- **速度与力度**：全曲速度标记、每段落的力度层级清晰一致；渐强渐弱的起止点明确；
- **奏法记号**：弦乐弓法（legato、détaché、pizz.、arco 转换）、木管吐音、铜管弱音器装卸时间（con sord. / senza sord. 前留小节）、打击乐器械说明一应俱全；
- **分部记谱**：div. 与 unis. 标注准确，分部期间的力度与奏法逐行写明；
- **特殊说明**：非常规奏法、器械准备（如换鼓、换槌）以文字注明。

## 分谱与排练

- **分谱**（parts）：从总谱抽取各演奏者声部，移调乐器的分谱必须再次核对移调方向；翻页位置安排在休止处；
- **可演奏性检查**：快速乐句、极低/极高音区、连续弱奏长音——逐段过一遍每种乐器的实际负担；
- **排练修订**：平衡问题几乎必然在排练中暴露——旋律被淹没就加叠或减伴奏，某件乐器太响就退力度或换手法。配器的最终裁判是音乐厅的耳朵，总谱永远是修订中的文档。
