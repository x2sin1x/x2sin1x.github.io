# 木管与铜管的和弦配置

木管与铜管都是单声部乐器：一件乐器一次只能奏一个音。因此乐队的和弦配置（scoring chords）本质上是**在多件音色各异的乐器之间分配和声声部**——这既是技术问题，也是趣味所在：同一条和声进行，叠置方式不同，色彩迥异。

## 基本原则：上密下疏

与弦乐相同，管乐和弦的排列遵循**上密下疏**：高音区声部靠近，低音区声部拉开。此外还需注意：

- **避开乐器脆弱音区**：和弦各音尽量落在每件乐器"说话最舒服"的中音区；
- **同族搭配优先**：同族乐器（如三支单簧管、四支圆号）奏和弦音色最融合，先在同族内配齐，再考虑跨族叠加。

一个木管四声部的 C 大调和弦，按"上密下疏"分配给四件乐器（按实际音高示意，暂不考虑单簧管移调）：

```abcjs
X: 1
T: 木管四声部和弦：上密下疏
M: 4/4
L: 1
K: C
V: 1 name="Fl." clef=treble
g' |]
V: 2 name="Ob." clef=treble
e' |]
V: 3 name="Cl." clef=treble
c |]
V: 4 name="Bsn." clef=bass
C, |]
```

大管在低音区取根音 c，单簧管在中音区取 c²，双簧管与长笛依次贴近地取 e²、g²——低音区疏、高音区密，且每件乐器都落在各自"说话最舒服"的音区。若把上方三声部也拉开到八度以上，高音区就会显得空而散。

## 木管和弦的叠置方式

以双管或三管编制为基础，常见叠置有：

- **同族并列**：2 支长笛 + 2 支双簧管各取两声部，或三管编制下长笛、双簧管、单簧管、大管各领一至两声部，音色纯而融合；
- **交叠**（interlocking / overlapping）：相邻声部由不同家族乐器交替占据，如"长笛—双簧管—长笛—双簧管"，音色交织如大理石纹，是印象派配器的标志手法；
- **包围**（encircling）：让一件音色突出的乐器（如英国管）居于其他音色之中，其音被"包裹"而不突兀；
- **纯色与混色**：同一和弦由单一家族奏出为**纯色**，多家族混合为**混色**——混色须防止某件乐器音量失衡（如双簧管天生比长笛响，叠置时或加长笛平衡，或将其移去）。

写作木管和弦时还要考虑**声部数量与编制的关系**：双管编制只有 8 支基本木管，一个七声部和弦几乎耗尽全部木管；此时要么精简和声，要么把部分声部交给弦乐或圆号。

## 铜管和弦的配置

- **圆号组**：四支圆号是乐队中最好的"和声填充器"——音色可强可弱、与木管弦乐皆融合，常用作持续的 softer 背景或中景和声；
- **小号 + 长号**：强奏高潮的骨架，小号领旋律或上声部，长号承担中低声部，大号铺底；排列同样上密下疏；
- **渐强设计**：铜管和弦常以"由弱渐强"的方式进入，写作时预先安排好各声部进出与力度层级。

四支圆号做和声填充的典型形态——中音区、密集排列、弱奏（按实际音高示意）：

```abcjs
X: 1
T: 四支圆号的和弦填充（中音区）
M: 4/4
L: 1
K: C
V: 1 name="Hn. 1" clef=treble
c' |]
V: 2 name="Hn. 2" clef=treble
g |]
V: 3 name="Hn. 3" clef=treble
e |]
V: 4 name="Hn. 4" clef=treble
C |]
```

四个声部挤在 c¹–c² 这一个八度之内，音色温润地融为一体；这种"中景和声垫"放在旋律与低音之间，既不抢戏，又把整个乐队的音响填满。

## 与弦乐的平衡

管乐与弦乐的数量悬殊决定了配平思路：**一支木管对一排弦乐，一支圆号对半个乐队**。常用对策：

- 木管旋律需突出时，或削减弦乐声部（弦乐改为拨弦、分部长音），或给旋律叠加同度/八度支撑；
- 铜管 forte 齐鸣时，弦乐若要保持存在感，必须以**齐奏、八度或震音**提高音响密度，而非维持纤弱的分部长音；
- 反之，弦乐轻声歌唱时，铜管应退到持续音或休止，让木管以弱奏点缀。

## 示例思路

配置一条大调终止式的思路示范：

1. 低音：大提琴 + 低音提琴 + 大管（+ 大号若 forte），八度铺底；
2. 内声部和声：中提琴 + 2 支圆号（弱奏）铺满中景；
3. 上声部：第一小提琴与长笛、双簧管同度或八度奏旋律，二提与单簧管填内声部；
4. 高潮点：小号加入旋律八度，长号补和弦根音与五音——层层"加色"而非一步到位。
