# 打击乐与色彩乐器的运用

打击乐与色彩乐器（竖琴、钢片琴、键盘等）在乐队中的份额不大，作用却不成比例——用对了是画龙点睛，用滥了则面目全非。本讲讨论它们的两大功能：**节奏**与**色彩**。

## 打击乐的节奏功能

- **结构强调**：定音鼓、大鼓、钹落在乐句与和声的关键点上，为音乐"打拍子"式的结构感——终止式、高潮音、段落转换处尤其常见；
- **推进渐强**：定音鼓滚奏配合吊镲滚奏，是管弦乐渐强的标准引擎；
- **节奏性格**：小军鼓的进行曲、铃鼓的舞曲、响板的西班牙风情——打击乐一响，风格立现；
- **点缀复节奏**：三角铁、铃鼓的细碎节奏插在弦乐音型之间，增加织体的光泽与活性。

## 打击乐的色彩功能

- **闪光点**：钟琴、三角铁在旋律高点上"点亮"一个音，类似绘画中的高光；
- **氛围底色**：锣的低鸣、吊镲的金属薄雾，可铺出神秘或庄严的远景；
- **音区延伸**：钢片琴、钟琴的极高音区是乐队自然音色之外的一层"星尘"（《胡桃夹子》《牧神午后》）。

## 定音鼓的和声职责

定音鼓是唯一常规参与和声的打击乐：

- 鼓音取当前调性的**主音与属音**（或五度、四度音程），转调时借踏板换音；
- 写作时在谱首注明所需鼓的数量与定音；
- 定音鼓渐强与全奏终止式相结合，是浪漫派管弦乐的招牌手法。

最常见的定音方案是主音与属音各一鼓：

::: abcjs
X: 1
T: 定音鼓的常见定音：主音与属音（C–G）
M: 4/4
L: 1
K: C clef=bass
[C,,G,,] |]
:::

大鼓定主音 C，小鼓定属音 G，两音构成纯五度，正好支撑本调最核心的两个和声支柱；转调时借踏板（或换鼓）重新定音，并在谱首注明所需鼓的数量与定音。

## 竖琴与键盘的色彩用法

- **竖琴**：琶音与刮奏装饰和声转换，泛音制造仙境光晕，闷音拨弦如低语；竖琴音量小，**独奏时须让织体退潮**；
- **钢片琴**：给旋律（通常与木管八度叠加）加一层水晶质感，音量极弱；
- **钢琴**：既可承担音型织体（与弦乐拨弦对答），也可作为"打击乐化的键盘"敲出色彩重音（巴托克、普罗科菲耶夫）。

## 克制的艺术

使用打击乐与色彩乐器前，先回答三个问题：

1. **这一击/这一笔让什么更清楚？**——节奏？高潮？段落感？
2. **能否由已有乐器承担？**——若圆号持续音已足够，就不必再铺一层竖琴；
3. **多久出现一次？**——色彩的价值来自稀缺：每次都响的三角铁，很快就会被耳朵过滤掉。

**少而准**，是打击乐配器唯一的黄金法则。
