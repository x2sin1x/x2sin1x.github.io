# 配器法

如果说乐器法回答"每件乐器能做什么"，配器法回答的则是"如何把这些能力组织成音乐"。本板块按乐队写作的实际流程展开：先从最基础的**弦乐组**写作入手，学习和弦在乐队中的排列与平衡；再扩展到木管与铜管的和弦配置，掌握多音色声部的叠置原则；随后依次处理旋律的音色选择与叠加、织体层次与低音声部、打击乐与色彩乐器的点缀；最后落到案头工作上——移调记谱、总谱读法与从钢琴织体到完成总谱的改编方法。

贯穿各讲的核心意识是**平衡**（balance）与**色彩**（color）：任何配器决定，最终都要在"能否听得清"与"是否好听"这两把尺子下接受检验。
