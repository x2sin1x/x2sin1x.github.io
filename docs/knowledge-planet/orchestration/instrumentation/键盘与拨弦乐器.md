# 键盘与拨弦乐器

这一家族的成员难以归入前四大家族：它们大多是**多声部乐器**——一人即可奏出和声与音型——因此在乐队中既可充当和声填充，也可贡献独一无二的色彩。

## 竖琴

**竖琴**（harp）是管弦乐队最重要的拨弦乐器，现代双踏板竖琴有 **47 根弦**（跨六个半八度，C₁–G₇）：

- **踏板机制**：七个踏板各对应一个音名，每档有降、还原、升三个位置；所有同名音（各八度）联动变音。因此**换踏板需要时间**，快速变音的片段须给演奏者留出余地，谱面上常以踏板记号标注；
- **奏法**：双手拇指朝上、四指朝内拨弦，一次可同时拨响多弦；**琶音**（arpeggio）与**刮奏**（glissando，双手拇指或食指沿琴弦快速滑过）是其标志语汇，刮奏中亦可借用踏板制造升、降音的色彩；
- **泛音**：以手掌根部轻触弦中点拨奏，音色缥缈如笛；
- **闷音**（sons étouffés）：拨后立即以掌心捂弦，音干而脆；
- **音区与音色**：低音区浑厚共鸣长，中音区清晰明亮，高音区纤细。竖琴音量不大，**独奏段落须削减其他声部**来衬托。

## 钢琴

**钢琴**（piano）自浪漫时期起进入乐队：既可承担"另一支乐队"般的和声与音型（如布拉姆斯《第二钢琴协奏曲》、拉赫玛尼诺夫《帕格尼尼主题狂想曲》），也可作为色彩点缀（如斯特拉文斯基《彼得鲁什卡》中两架钢琴对垒）。它在总谱中记实际音高，用大谱表，功能介于打击乐与色彩乐器之间。

## 钢片琴

**钢片琴**（celesta）外观如小立式钢琴，击槌敲击钢片发声。音色纯净空灵，如仙境之铃。**记谱比实际音高低一个八度**。音量极弱，使用时务必让乐队"退后"。

## 管风琴与簧风琴

- **管风琴**（organ）：以音栓选择不同音色组合，脚踏键盘（pedal）承担低音，音量层次由音栓与送风决定；用于教堂场景与宏大段落（圣-桑《第三交响曲》、马勒《第八交响曲》）；
- **簧风琴**（harmonium）：自由簧发声，音量小、音色怀旧，多见于室内乐编制与仿古风格。

## 吉他与曼陀林

- **吉他**（guitar）：现代古典吉他六弦（E–A–D–G–B–E），记谱比实际**高八度**；拨弦音色亲切，弹拨（rasgueado）与指弹皆可。管弦乐中偶见独奏段落（如罗德里戈协奏曲为吉他与乐队而作）；
- **曼陀林**（mandolin）：八弦四组、按小提琴定弦，以拨子快速重复拨弦（tremolo）见长，音色清脆明亮（莫扎特《唐璜》小夜曲、马勒《第七交响曲》）。

## 写作要点

1. **音量平衡**：本家族大多音量偏小，与乐队同响时须削减对方声部或为其配弱奏背景；
2. **技术可行性**：竖琴踏板、钢琴手位跨度、曼陀林拨奏速度都需在谱面可执行的范围内；
3. **色彩定位**：这些乐器出现在乐队中，几乎总是为了“别的乐器给不了的那个颜色”——写作前先问：这里需要它们的那一味色彩吗？

## 音域一览（实际音高）

以下谱例按**实际音高**标注本家族主要乐器的音域；钢片琴与吉他为移调记谱，差异在标题中注明：

```abcjs
X: 1
T: 竖琴 C1–G7
M: 4/4
L: 1/2
K: C
V: 1 clef=treble
"G7"g''2 |]
V: 2 clef=bass
"C1"C,,,2 |]
```

```abcjs
X: 1
T: 钢琴 A0–C8
M: 4/4
L: 1/2
K: C
V: 1 clef=treble
"C8"c'''2 |]
V: 2 clef=bass
"A0"A,,,,2 |]
```

```abcjs
X: 1
T: 钢片琴（实际 C5–C8，记谱低一个八度）
M: 4/4
L: 1/2
K: C clef=treble
"C5"c2 "C8"c'''2 |]
w: 低音区 高音区
```

```abcjs
X: 1
T: 吉他（实际 E2–B5，记谱高八度）
M: 4/4
L: 1/2
K: C clef=treble
"E2"E,,2 "B5"b2 |]
w: 低音区 高音区
```

```abcjs
X: 1
T: 曼陀林 G3–C6
M: 4/4
L: 1/2
K: C clef=treble
"G3"G,2 "C6"c'2 |]
w: 低音区 高音区
```
