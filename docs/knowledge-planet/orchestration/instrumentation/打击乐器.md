# 打击乐器

打击乐器以敲击发声，是乐队中最古老的家族。它们在总谱中虽常处于"沉默"，但每一次出场都目的明确：或击出节奏的骨架，或砸下结构的关键点，或洒下一片色彩的闪光。按音高可分为**有固定音高**与**无固定音高**两类。

## 定音鼓

**定音鼓**（timpani）是打击乐组的核心，由一只鼓手演奏 2–5 只大小不同的鼓：

- 每只鼓的音域约**纯五度**（大鼓约 D₂–A₂，小鼓约 F₃–C₄），通过踏板或调音螺丝改变鼓皮张力定音；
- 传统写法按 C–G 记谱（实际音高以谱面为准，现代作品须标明实际音），并逐一注明所需鼓与音高；
- 定音鼓的**滚奏**（tremolo）可以从 ppp 渐强至 ff 再收回，是管弦乐渐强的经典推进器；
- 定音鼓**参与和声**：鼓音通常取自当前和声的主音与属音，转调换音需借踏板或重新定音的时间。

## 无固定音高打击乐

- **小军鼓**（snare drum）：一面蒙鼓皮、底下张响弦（snares），音色干裂锐利；滚奏、边击（rim shot）、边敲（rim click）、去响弦等奏法丰富，是节奏性的灵魂；
- **大军鼓**（bass drum）：低沉浑厚，常与钹同时击出"隆重一击"；
- **钹**（cymbals）：对击（piatti）与吊镲（suspended cymbal，用鼓槌滚奏或刮奏）两种用法，后者可做长渐强；
- **三角铁**（triangle）：金属细鸣，弱奏晶莹、强奏穿透一切；
- **锣**（tam-tam / gong）：轰鸣式的低沉金属声，消音绵长；
- **铃鼓**（tambourine）、**响板**（castanets）、**鞭子**（whip）、**木鱼**（wood block）等各有民族与色彩用途。

无固定音高打击乐以 **x 谱线或单线**记谱，符杆方向区分左右手或不同槌法。

## 有固定音高打击乐

- **木琴**（xylophone）：硬槌敲击木条，音色干、脆、亮，记谱比实际**低八度**，快速断奏轻巧滑稽；
- **马林巴**（marimba）：木条更宽、槌软，音色温润低暖，音域可达四至五个八度；
- **颤音琴**（vibraphone）：金属条配电机驱动旋转盘，产生**颤音**；踏板控制延音，音色朦胧如水波，爵士乐队中的主角；
- **钟琴**（glockenspiel）：钢片发声，记谱比实际**低两个八度**，音色如星光闪烁；
- **钢片琴**（celesta）：键盘击弦片发声，记谱比实际**低一个八度**（《胡桃夹子》"糖梅仙子之舞"）；
- **排钟/管钟**（chimes / tubular bells）：竖立金属管模拟教堂钟声，庄严肃穆。

有固定音高打击乐用普通五线谱记谱，谱号按实际音区选择；多件乐器可由一人分担，谱面须标明乐器交替（如 xyl. → glsp.）与所需准备时间。

## 打击乐写作要点

1. **一人多器**：一位演奏者同时负责多件打击乐，写作时注意器械摆放距离与换手时间；
2. **克制**：打击乐是"味精"，滥用即失灵。里姆斯基-科萨科夫的告诫——"打击乐的效果在于节制"——至今有效；
3. **目的明确**：每一击都应回答“为什么敲”——强调节奏？点亮色彩？推进渐强？说不清目的的一槌就是多余的一槌。

## 音域一览（实际音高）

有固定音高的打击乐器音域如下（无固定音高打击乐不适用；木琴、钟琴的记谱与实际音高相差八度或两个八度，已在标题中注明）：

```abcjs
X: 1
T: 定音鼓（大鼓 D2–A2，小鼓 F3–C4）
M: 4/4
L: 1/2
K: C clef=bass
"大鼓 D2–A2"D,,2 A,,2 | "小鼓 F3–C4"F,2 C2 |]
```

```abcjs
X: 1
T: 木琴（实际 C5–C7，记谱低八度）
M: 4/4
L: 1/2
K: C clef=treble
"C5"c2 "C7"c''2 |]
w: 低音区 高音区
```

```abcjs
X: 1
T: 马林巴 C2–C6
M: 4/4
L: 1/2
K: C clef=bass
"C2"C,,2 "C6"c'2 |]
w: 低音区 高音区
```

```abcjs
X: 1
T: 颤音琴 F3–F6
M: 4/4
L: 1/2
K: C clef=treble
"F3"F,2 "F6"f'2 |]
w: 低音区 高音区
```

```abcjs
X: 1
T: 钟琴（实际 C6–C8，记谱低两个八度）
M: 4/4
L: 1/2
K: C clef=treble
"C6"c'2 "C8"c'''2 |]
w: 低音区 高音区
```
