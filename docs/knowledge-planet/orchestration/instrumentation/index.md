# 乐器法

乐器法是配器的第一步：在把音色组织成音乐之前，必须先了解每一件乐器本身。本板块按管弦乐队的五大乐器家族展开——弦乐、木管、铜管、打击乐、键盘与拨弦乐器，逐一梳理各乐器的构造与发音原理、音域与音区特征、基本演奏技法与记谱惯例，并以"管弦乐队与总谱"一讲开篇，交代乐队编制的沿革与总谱的排列规则。

学习乐器法时建议抓住三条主线：**音区**（每件乐器的低、中、高音区音色与可控性的差异）、**技法**（弓法、吐音、弱音器等改变音色的手段）与**记谱**（实际音高与记谱音高的关系）。配器中的绝大多数失误，都源于对这三条主线中某一条的忽视。
