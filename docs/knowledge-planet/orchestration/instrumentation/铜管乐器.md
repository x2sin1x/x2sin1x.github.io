# 铜管乐器

铜管是乐队的力量之源：辉煌、庄重、气势磅礴。它以唇振动发声，音色统一性强，能在极强奏时压倒整个乐队，也能在弱奏时呈现不可思议的柔和。现代铜管普遍配备**活塞**（valve）或**拉管**（slide），可以奏出完整的半音阶，但在音响特质上仍保留着泛音列的"出身"。

## 发音原理

演奏者以双唇振动吹嘴发声，唇部张力决定激发管内空气柱的哪一**泛音**：不加任何装置时，一件铜管乐器只能奏出基音上方的泛音列——这正是亨德尔时代"自然小号"只能吹出分解和弦式号角音型的原因。活塞通过接通附加管长来降低泛音列，从而补齐半音；长号则用拉管连续改变管长。

铜管的音区概念与木管不同：**音色相对统一**，但极高音区（走"泛音列上方"）需要极强的唇部控制，低音区（基音附近）则浑厚而迟钝。铜管 forte 容易、piano 需要功夫——与木管恰恰相反。

## 圆号

- **圆号**（French horn）：F 调，记谱比实际**高纯五度**，音域约 B₁–f²（记谱）。音色圆润宏大，可柔可刚：弱奏时与木管水乳交融，强奏时又有铜管的辉煌，是连接木管与铜管的"桥梁"。
- 圆号以**右手入喇叭口**调节音色：手平伸为常态；手掌塞紧喇叭口则产生**阻塞音**（bouché / stopped tone），音色金属般尖锐，记谱在音符上加圈点（o 或 +）；另有**活塞阻塞**（stopped via valve）与**弱音器**两种近似效果。
- 乐队惯用**四支圆号**：一、三号偏高中音区，二、四号偏低音区，交叉叠置以保证旋律不间断与和声的饱满。
- 圆号**气息消耗极大**（管长超过 3.7 米），强奏高音区后必须安排休止。

## 小号

- **小号**（trumpet）：现代乐队以 C 调与降 B 调小号为主，降 B 调记谱比实际**高大二度**。音域约 f♯–c³（记谱），音色明亮、庄严、极具号召力，是军号式音型的天然载体。
- **短号**（cornet）音色更圆润甜美；**降 E 小号**比降 B 调高纯四度，高音区轻便，常用于马勒、施特劳斯的作品。
- 小号吐音敏捷清晰，从庄严的连音到轻快的双吐皆能胜任；弱奏时亦可融入木管式的轻声。

## 长号

- **长号**(trombone):以拉管改变管长,共**七个把位**,次中音长号音域约 E₂–B♭₄（实际）。音色庄重宏伟,庄严的圣咏式写法是它的经典语境;同时它也是唯一能奏出**真正连续滑音**(glissando,同把位内仅限半音内,跨把位的滑音常带"牛吼"效果)的铜管。
- 长号把位与音准的关系直观，断句清晰，吐音有力；弱音器（直塞、杯形、帽子、harmon 等）种类丰富，从忧郁的呜咽到滑稽的"哇哇"声应有尽有。
- **低音长号**（bass trombone）加装活塞下探更低音区，承担铜管组的最低声部之一。

## 大号

- **大号**(tuba):乐队的铜管低音基础,常用降 B 调与 C 调大号,记谱为实际音高(低音谱表)。音域约 D₁–F₄，低音区浑厚如雷,中音区温厚。大号气息消耗巨大,快速乐句应避免;它与低音长号、低音提琴共同构成乐队音响的最底层。

## 弱音器与力度特性

- **弱音器**（mute）塞入喇叭口改变音色：直塞（straight）使音色收窄发暗，杯形（cup）产生朦胧的"捂住"感，harmon 弱音器可奏出滑稽的远距离喇叭声。谱面以 con sord. / senza sord. 标记，并需留出**装卸弱音器的时间**；
- 铜管**突强（sforzando）与快速渐强**是强项，**长渐弱到极弱**则是难点；写作时应顺应"起音易猛、收音需控"的物理特性。

## 铜管组的角色

四支圆号、三支小号、三支长号、一支大号构成标准铜管组。它的功能光谱从和声背景(圆号持续音)、对位线条(长号声部)到高潮齐奏(全组 forte)不等。铜管 forte 时音量惊人，配器时须为木管与弦乐留出“生存空间”——这是平衡课题中最常被违反的一条。
