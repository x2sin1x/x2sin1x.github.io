# 配器

**配器**（Orchestration）是研究如何为管弦乐队或其他乐器组合写作音乐的学问。它回答两个相互衔接的问题：一是每种乐器**能做什么、擅长做什么**——这是**乐器法**（Instrumentation）；二是如何把不同乐器的音色、音区与演奏法**组织成一个有机的整体**——这是**配器法**（Orchestration）。如果说和声赋予音乐以纵向的色彩，那么配器就是让这色彩流动起来、有了体温和光线的学问。

本模块分为两大板块：

- **[乐器法](/knowledge-planet/orchestration/instrumentation/)**：以阿德勒《配器法教程》（Samuel Adler, *The Study of Orchestration*）的乐器分类为主线，逐一梳理弦乐、木管、铜管、打击乐与键盘拨弦五大家族的构造、音区、音色特征与演奏技法，并介绍管弦乐队的编制沿革与总谱读法基础。
- **[配器法](/knowledge-planet/orchestration/orchestration-technique/)**：从乐队写作的实践流程出发，梳理弦乐组的写作、木管与铜管的和弦配置、旋律的音色处理与叠加、织体与低音声部的安排、打击乐与色彩乐器的运用，直至移调记谱、总谱读法与从钢琴织体到总谱的改编方法。

## 前置知识

学习配器前建议先掌握基本乐理与基础和声，可参考 [乐理](/knowledge-planet/music-theory/) 与 [和声](/knowledge-planet/harmony/) 模块；对各种音程、和弦结构与调性逻辑的熟悉程度，直接决定配器写作时"听得见"与"写得出"之间的距离。
