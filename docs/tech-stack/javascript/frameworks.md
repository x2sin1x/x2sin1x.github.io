# 理解客户端 JavaScript 框架

> 本节目标：知道客户端框架解决的问题，并在学习框架前具备足够的原生 JavaScript 基础。

## 框架解决什么问题

客户端框架为组件组织、界面状态和更新流程提供一套约定。它们帮助大型交互应用保持结构一致，但不会替代 JavaScript、HTML、CSS、浏览器 API 或网络基础。

## 学习顺序

开始框架前，先能独立使用函数、数组和对象，理解模块、事件、DOM、异步请求及错误处理。这样看到组件、状态和属性时，可以把框架 API 与语言机制区分开。

不同框架在模板/JSX、响应式状态、路由和构建工具上选择不同。选型应结合项目已有技术、团队经验和部署约束，不应仅凭教程热度决定。MDN 的[客户端框架系列](https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Frameworks)提供进一步对比与入门资料。

## 小结与练习

- 框架管理大型界面的组件和状态，不是学习 JavaScript 的前置条件。
- 掌握 DOM、事件、模块和异步后，更容易理解框架抽象。
- 具体框架 API 会变化，学习时以其官方文档为准。

练习：用一段话解释“状态”“组件”和“DOM”分别是什么，并说明哪些是 JavaScript 语言概念，哪些来自框架或浏览器。
