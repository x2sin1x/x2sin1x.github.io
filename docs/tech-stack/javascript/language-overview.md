# JavaScript 语言概述

> 本节目标：把核心语言概念放入同一张图景，知道哪些行为由 ECMAScript 定义，哪些由宿主决定。

## 语言与宿主

ECMAScript 定义语法、值、对象、函数、模块和内置对象。运行时提供宿主环境：浏览器暴露 DOM 和 Web API，Node.js 暴露进程、文件和服务器 API。语言规范不规定浏览器页面如何绘制，也不规定 Node.js 文件路径 API。

## 重要特征

JavaScript 是动态类型语言，变量绑定不预先声明静态类型；函数是一等值，可赋给变量、作为参数传递和从函数返回；对象基于原型委托；类语法在原型机制上构建。语言支持命令式、面向对象和函数式写法。

JavaScript 在常见浏览器环境中由一个主线程执行 JavaScript 任务，但宿主可通过 Worker 提供其他线程。单线程不意味着没有异步，也不意味着所有宿主行为都同步完成。

## 程序执行

代码由语句和表达式构成。函数调用创建执行上下文；闭包关联词法环境；异步任务通过宿主调度与事件循环在后续时机执行。模块建立独立作用域和显式依赖关系。
